## 4. 让 Claude Code 重构了一个 1500 多行的函数，测试全过了，但我还是不太放心

## 5. 24 GB Mac 零 Swap 并发 160 个 AI 浏览器：干掉 Node MCP 后连 Chrome 自身也省了 503 MB

**摘要**：作者给自己的 Rust 项目 sessfork 补了通用 `--cdp-url`，能直接挂原版 Chrome（不用装 Moli），在 24GB MacBook 上压到 80% 内存熔断线做极限测试。对比官方 Node `@playwright/mcp`：冷启动从 1240ms 降到 3.2ms（388 倍），总 RSS 省 748MB，其中 **Chrome 自身渲染器就降了 503MB**，因为原生 CDP 的 `Accessibility.getFullAXTree` 不往每个 V8 堆注入 Playwright 的 JS。并发送从约 22 个提到 56 个，配 Moli 独立进程可到 160 个（约 93MB/Agent）。还测出一个真实 bug：moli 单进程压到 60 个 context 就达到 `FD_SETSIZE` 上限 1024，已提 issue 且维护者认领。

**评论**：该帖暂无回复，作者给了本地一键复现脚本（`bench_scale.py --swarm-ceiling`、`security_verify.py`），不碰真实浏览器数据，可自行验证。
