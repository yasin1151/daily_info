### 1. Codex 额度争议：OpenAI 官方回应"订阅套利"，社区回怼"额度就是个黑盒"

- **新闻/帖子本身**：OpenAI Codex 负责人 Thibault Sottiaux 针对社区"用量限制被偷偷调整"的传言发推回应（2797 赞 / 1426 回复）：官方从未未经沟通就改动限制，受影响用户大多在用 sub2api 把订阅流量转成 API 流量再分发给多人，这类"订阅套利"会被欺诈防护系统标记；用官方客户端或开源客户端正常使用完全没问题。同一天 V2EX 有用户用任务记录实测反推 20X 周额度约 6 万 credits，得出"没明显缩水"结论，但评论区体感完全相反，额度黑盒成为核心争议。

  - V2EX 1 楼："我的是 5x pro，我也感觉没缩，这其实就是 openai 鸡贼的地方，完全是一个黑盒。每个人只能靠感觉推断，有说缩水的也有说没缩的" —— 点破 OpenAI 额度不透明的本质：官方不给数据，用户只能靠体感互相猜。

- **来源**：HackerNews + Anthropic Engineering

- **新闻/帖子本身**：开源项目 NoBuzz 提供 Claude Code skill `/debuzz`，把 Claude 上一条回复丢给 Gemini CLI 重写，"从千禧一代点击诱饵腔翻译回正常英语"，演示里 Claude 写 "load-bearing assumption…and this is the kicker"，Gemini 版直接列出三个 bug 加修复方案。帖子在 HN 拿到 169 赞、121 条评论，集中爆发用户对 Claude 文风的积怨。同一天 Anthropic Engineering 发布复盘：所谓"Claude 变笨"确有其事，是三处独立改动叠加——默认 reasoning effort 从 high 降为 medium、空闲会话 thinking 被误清导致"失忆式重复"、降冗长提示词伤代码质量，v2.1.116 已全部修复，API 未受影响。
- **社区原话摘录**：
  - HN 评论者："这是对 Anthropic 产品的悲哀控诉：这么多人讨厌和它交互。Claude 正走向 Microsoft Teams 式的被恨区。" —— 直指产品体验已积累起大规模反感情绪，不是个别用户挑剔。
  - HN 评论者："切到别的模型才意识到 Claude 有多啰嗦。说教感尤其烦人——想起我在为这些 token 付费的那一刻就完全无法忍受了。" —— 付费用户对"说教腔加啰嗦"零容忍，文风问题直接伤及付费意愿。
  - HN 评论者："Anthropic 明确选择了人格化模型。Codex/Sol 几乎不用人称代词、不用最高级……它的口头禅我也烦，但没那么讨厌。" —— 对比 Codex 的克制风格，认为这是 Anthropic 的产品路线选择，不是偶然缺陷。
- **参谋部短评**：官方复盘承认"为速度牺牲智能是错误权衡"并回滚，这个表态比修复本身更值得记；社区自制嘲讽工具加官方认错同日出现，Claude 的文风和默认行为取舍短期内还会是话题。
- **链接**：https://github.com/adnanakil/nobuzz ｜ https://www.anthropic.com/engineering/april-23-postmortem

### 5. HN：沙箱 Agent 软件工厂的"几乎全自托管"实验，本地模型的真实体验来了
- **来源**：HackerNews
- **一句话人话版**：有人用一条提示词搭了全自动 Agent 软件工厂，专门买旧服务器做隔离、每月只花 20 美元的 Codex 订阅，评论区全是自托管 GPU 跑本地模型的一手经验。
- **新闻/帖子本身**：作者用一条提示词让 Agent 独立完成从建 repo、写代码和测试、CI 跑绿、部署 Postgres 到 HTTPS 上线的完整流程。关键设计是不给 LLM 碰主机，专门买台 10 代 i7 旧服务器做结构隔离，自托管 Coolify，唯一持续成本是每月 20 美元的 Codex 订阅。HN 上 48 条评论几乎全是自托管 GPU 跑编码模型的一手体验，从 Qwen 27B 的实测速度到"推理还是得靠云端 API"的吐槽，沙箱安全边界和本地模型现实被摊开讨论。
- **社区原话摘录**：
  - HN 评论者："RTX 5090 上 Qwen 3.8 27B 约 180 TPS，输出质量大致对齐 Opus 4.5-4.6，这个 20GB 文件真的能自己写软件。" —— 本地开源模型已能扛起部分编码任务，给出了质量对齐旗舰闭源模型的实测数据。
  - HN 评论者："叫'几乎'是因为没看到 GPU——有人自托管 GPU 跑编码模型吗？我的体验……不怎么样，前沿模型还是得靠大厂 API。" —— 自托管派泼冷水：前沿模型的质量差距仍在，本地跑编码模型体验一般。
  - HN 评论者："用 Codex 做推理" —— 一句话吐槽作者说好的自托管，推理环节还是走了云端 API，沙箱边界与成本现实之间存在张力。
- **参谋部短评**：Agent 沙箱安全边界（隔离 vs 信任）是当前 Agent 工程的核心议题，加上本地模型质量到底追没追上旗舰的实测争论，这条值得继续盯，后续会有更多实测数据补上来。
- **链接**：https://blog.jakesaunders.dev/building-an-almost-fully-self-hosted-sandboxed-agentic-software-factory/
