- **89 楼 zl157394168（❤3）**：往下挖了一层——“我发现 kind=443 的才有趣，很多 18🈲”

## 2. Claude Code 把你的邮箱写进每个请求的 User-Agent，GitHub issue 已有 909 个 reaction

V2EX 这条是转述，我去核实了原 issue（anthropics/claude-code #107757，11-05 开的，现在 open、98 条评论、909 个 reaction）。举报人说自己每天收到几十封诈骗邮件，抓包发现本地跑的 Claude Code 联网搜索时，会把真实个人邮箱写进 HTTP 的 `User-Agent` 里——每抓一个网页，邮箱就进一次对方服务器日志。他的要求很明确：“这不该是一个可以 opt-in/opt-out 的设置，它应该从 harness 里彻底删掉。”

- **issue 里 Anthropic 员工 poteat 的官方回复**：没有删除那行代码，而是说“v2.1.317 起内置了一个 `cc-plugin-privacy` mod 来确定性地阻断这个行为，默认开启，可以在 `/plugins` 里关掉”，并承诺会把内置 mod 源码放出来。
- **高赞回复（Netkas / eepymeowers）**：一句“`Corporations care about your privacy` Lol”，一句“you thought anthropic cared?”——900 多个 reaction 里很大一部分是在围观。
- **pulasthibandara**：“Well, no one is responsible when everything is vibed. Blame the agent.”

值得关注：V2EX 楼主的吐槽抓住了重点——“源码里删掉拼邮箱那行只要几秒钟，官方却去加了个插件来拦”。技术上这是“用一层 mod 盖住一个本来不该存在的行为”，而这种处理方式在 Agent 工具里越来越常见：**默认行为先上线拿数据，出事再加开关**。对本地跑 Agent 的人，这是个提醒——你给出的文件、终端、网络权限，最终都会以某种 header 形式流出。

- **1254865「无人在意的角落，idea 2026.3 发布了」（69 楼）**：楼主只写了一句“都是 AI 方面的功能”。**14 楼 scemsjyd（❤13，本帖最高赞）**说“只有我每次 ai 写完代码，我自己还要用 idea 再 review 一遍的吗？”——这是全场最实在的一句：IDEA 剩下的价值是“人审 AI 代码的场所”。**3 楼 stabc（❤8）**：“听说古代程序员用这个东西手写代码？” **10 楼 HTML001（❤1）**：“现在基本只是用来当 git 可视化工具用了”。
- **1255109「很久没开 JetBrains 家产品了」**：楼主说 16 年发微博说等有钱了买 IDEA，“结果现在有钱了也不用买了，变成了买 token 了。打败 IDEA 的不是更优秀的编译器，而是 AI”。**3 楼 konakona**：“20$ 买 tokens 更香”。

值得关注：这组帖子真正的信息不是“JetBrains 要死”，而是**开发工具的估值锚点换掉了**——过去按“功能多少、重构多强”定价，现在按“能不能让我审 AI 的输出更快”定价。IDEA 退化成“review 面板 + git 界面 + 启动器”，这个路径和 eclipse 当年一模一样。同时注意 OpenIdea 这类复刻产品的传播方式：一天之内多个帖子互相引流，已经有人怀疑是水军，看这类推荐帖要打折。

- **11 楼 zhuanggu（❤9）**：把话题从技术拉到分配——“我们天天看出口多少多少、营收多少多少，可是钱都被税收了、被企业赚了，生产者分配到的依然很少，手里没有钱怎么敢消费？……我们看起来是对外倾销了廉价的商品，实际上倾销的是廉价的劳动力。”
- **3 楼 yidinghe**：“‘职业生涯’这个概念已经从越来越多的行业当中消失了。”

值得关注：这是今天评论区质量最高的一条。它没有停在“AI 会不会取代我”，而是把 AI 当成一次**成本坍塌事件**去推演分配后果——这个视角比“某个岗位消失”更接近现实。20 楼那个封号比喻之所以拿最高赞，是因为它同时说出了两件事：不确定性，加上没有申诉渠道，这恰好也是今年 V2EX 上 Claude 用户的主要体验。
