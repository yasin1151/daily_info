## 3. [开源] OxideTerm：Rust + GPUI，把终端的内存砍掉 92%

https://www.v2ex.com/t/1255952

**摘要**：作者把 SSH 客户端从 WebView 迁到 Rust + GPUI，四个月从 2.0.11 迭代到 2.3.1。这轮重点不是加功能而是打磨基本功：解析放后台线程、批量处理文本与网格写入、历史文本和样式分离紧凑存储，2 万行历史 + 400 列场景下保留堆从 196.47MB 降到 15.50MB（-92.1%）。新功能里最值得看的是向外部 AI 客户端开放的 MCP 接口，让 Codex 之类经授权直接调用连接、终端、文件工具，权限可撤销。

**为什么值得看**：国产开源终端里少有的真去优化吞吐和内存，而且在内存涨价的当口给出实测数据；把 MCP 接进终端也是个新方向。
