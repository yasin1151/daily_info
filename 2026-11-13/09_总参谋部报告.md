### 2. Gemini 4 Hydrogen 上线：一个 Flash 档模型胜过了自家 Pro，评论区都在批评命名和价格

- **来源**：HackerNews（421 分 / 280 评论）+ Google 官方发布
- **一句话人话版**：Google 把 Gemini 应用和搜索里的 3.8 Flash 直接换成 Gemini 4 Hydrogen，速度更快，价格没降。
- **新闻/帖子本身**：官方口径是速度约为 3.8 Flash 的 2.5 倍，定价与未打折的 3.8 Flash 持平。第三方榜单上 Hydrogen 拿到 54 分，超过上一代 Pro 级 Argon 的 50，逼近 GPT-6.1 Sol 与 Claude Sonnet 5.5 的 55——一个低阶档模型超过了自家 Pro 的分数。同一天 Antigravity 发布 Orchestrator，让编排层自己决定子任务交给哪个模型。在 HN 的 280 条评论里，讨论最多的是命名和价格，而不是能力。
- **社区原话摘录**：
  - HN 评论者（11 条回复）：“按复杂度和成本排是 Hydrogen → Argon → Carbon。这算什么顺序？按原子量、宇宙丰度排都该是 Hydrogen→Carbon→Argon。” 他逐条排除了字母序、电负性、沸点、Scrabble 得分和易燃等级，结论是这套命名不服从任何化学直觉。—— 讨论热度最高的话题跟模型强弱无关，说明产品线叙事本身已经失控。
  - HN 评论者：“Hydrogen 定价和未打折的 3.8 Flash 一样，远高于现在大家实付的 Flash 价，Google 是不是放弃了 fast and cheap 这一层？等 3.8 Flash 年底折扣结束，一堆企业客户只能换供应商。” —— 最实际的一点是：折扣期结束才是真正的价格测试点。
  - HN 评论者：“访问门槛高、定价不透明、经常宕机，我受够了。” —— 这条情绪化但指向明确，抱怨的是可用性和信息透明度，不是跑分。
- **参谋部短评**：值得关注的不是 54 分，而是“便宜好用”这个位置还会不会继续提供吸引人的方案。同日的 Orchestrator 也有人不买账——有人觉得把调度权交给模型让人紧张，因为模型对自己的能力往往过于乐观。

### 5. 44 个 MCP server，30 个七天零调用：工具膨胀第一次有了数字

- **来源**：Reddit r/ClaudeCode
- **一句话人话版**：有人翻了自己七天的会话日志：44 个 MCP server、720 个工具，真正被调用过的只有 121 个。
- **新闻/帖子本身**：楼主统计了七天 68 个会话，共发生 2,206 次 MCP 调用，只用到 121 个不同工具；44 个 server 里有 30 个一次都没被调用，最大的闲置 server 自带 74 个工具。调用高度集中，浏览器控制一项占 62%，前四名合计 86%。这些闲置项大多不是手动添加，而是随插件和账号连接器一起进来的，其中 22 个连登录都没做过。他没有断言闲置工具的确切开销，只问一句：精简之后首个请求真的变小了吗，还是工具检索已经把它们挡住了。
- **社区原话摘录**：
  - Reddit 评论者（4 赞·归档快照）：“With tool search on, which is the default, the first request already hides most of it.” 他解释默认只加载工具名和各 server 的说明，完整定义要等模型去搜；两个例外是配置了强制加载，以及关掉检索或工具还很少时的自动阈值模式。—— 正面回答了楼主的疑问：720 个工具主要是 720 个名字，不是 720 份完整定义。
  - Reddit 评论者（3 赞·归档快照）：“it neither fetches nor connects any of them” —— 那十几个账号连接器是工具自己去拉的，可以在项目配置里关掉，属于能立刻照做的减法。
  - Reddit 评论者（2 赞·归档快照）：“no MCP servers: 43,154 input tokens” 他做了裸跑对照：不挂 MCP 时输入 43,154 token，挂一个 22 工具的 server 后变成 44,908，约 1.7k 增量，而且无论是否开启工具检索，数值都不变。—— 本轮唯一的实测数字，但作者也承认没测过 44 个 server 那种规模。
- **参谋部短评**：这条把“工具装太多”从感觉变成了数字。真正的麻烦不是该删谁，而是没人知道自己装了什么——工具清单已经变成需要定期审计的资产。
- **链接**：https://www.reddit.com/r/ClaudeCode/comments/1xtm77g/
