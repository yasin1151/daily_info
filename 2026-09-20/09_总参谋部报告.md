### 1. 智谱 ZCode 被扒出静默上传整个工作区，官方回应被指公关失败

  - V2EX 17 楼："所以他的意思就是 GLM 服务器资源充足，主动地为每个小用户的每个小 git repo 建一个云端的 wiki，这么慷慨？" —— 不信服官方对功能的定性，认为实际行为超出功能说明的范围。

### 2. Claude Code 额度被用户逐条算了一遍：子代理缓存只有 5 分钟，周额度实际缩水约 58%

- **来源**：Reddit r/ClaudeCode
- **一句话人话版**：有人把会话日志按列表价逐条计价，算出周额度缩水约 58%；另一条帖子指出子代理的 prompt cache 默认只活五分钟，长命令就能烧掉整个 5 小时窗口。
- **新闻/帖子本身**：一条技术帖把"额度掉得莫名其妙"拆成机制问题：主会话的 prompt cache 在订阅计划上能活一小时，但子代理默认只有五分钟。子代理上下文动辄三十万到六十万 token，一旦它卡在某次完整测试扫描、构建或 git hook 里超过五分钟，缓存过期后整段上下文要重新写一遍缓存，六个长测试就是六次全量重写，五小时窗口就这么没了。解法是一行配置：把子代理的缓存 TTL 设为 1 小时。另一条帖子用两个高配账号 24 小时跑 Claude Code，把会话日志按消息 id 去重、逐条按列表价计价再除以用量表百分比，算出上周每个百分点约 55 美元、本周约 23.5 美元，判断周额度实际缩水约 58%，而官方口径是 17%。
- **社区原话摘录**：
  - Reddit 评论者（归档快照，赞数不可得）："subagentPromptCacheTtl 是正确杠杆，另一半是根本不要在子代理里阻塞：把长命令丢到后台再轮询，请求之间的间隔就永远不会接近缓存窗口……效果一样，但不依赖更长的 TTL 熬过一次重启。" —— 补上发帖人没说的另一半，指出改执行方式比改配置更稳，长 TTL 也会因重启失效。
  - Reddit 评论者（同帖）："我做 Rust，几周前这个问题咬得特别狠……基本思路是主 agent 用 high effort，子代理用 low effort。" —— 把机制落到具体工作流：cargo test 动辄五分钟以上正是典型缓存杀手，并给出 effort 分层的配套做法。
  - Reddit 评论者（额度审计帖）："缓存写入那一行才是真正的伤害来源：你那周 540 美元是写入而不是读取，写入按 1.25 倍计价……值得查清是什么那么频繁地让前缀失效。" —— 对"缓存读取被重新加权"的技术性反证，认为高估可能来自计价口径而非官方改规则。
  - Reddit 评论者（同帖）："你要明白那仍然是 2350 美元的用量只收你 200 美元。投资者的钱不是无限的，这些公司最终得停止发放补贴。" —— 反方立场：认为抱怨补贴缩水站不住脚，这类"用户 vs 补贴可持续"的对立是当下订阅争议的核心。
- **参谋部短评**：这条的实用价值是给出了一套普通用户可复现的额度审计方法，并且把抱怨拉回机制层面。缩水幅度到底是 17% 还是 58%，取决于计价口径，值得继续盯官方的定价说明。

### 3. "我一年前就做过"：被包装成全新突破的非自回归模型遭社区当场核对

- **来源**：Hacker News
- **一句话人话版**：一家公司把"非自回归决策模型"包装成新突破，一位更早发表并开源过的开发者发文对峙，讨论很快转向"叙事包装才是定价权"。
- **新闻/帖子本身**：有开发者在 2025 年 3 月就发表论文、开源权重和数据集，用强化学习从对话序列直接输出转化概率，当时只在开发者社区发了一条标题晦涩的帖子。2026 年 9 月，另一家初创提出同样的"非自回归决策"概念，无论文、无开源权重、无数据集，报出每百万输入 token 极低的价格和约 150 毫秒延迟，被包装成新科学突破。原作者随后重建了一套全开源版本，宣称单卡 32.8 毫秒、比对方快 6 到 8 倍、Apache 2.0 许可。
- **社区原话摘录**：
  - HN 评论者（最高赞）："老故事了——人们不明白营销和品牌至少和产品一样重要。Jev 的品牌做得极好，看一眼网页就秒懂它的含义。而原作者的'营销'只是 Reddit 上一个叫'用纯强化学习从对话预测销售转化概率'的帖子。你能看懂这是什么吗？我不能。" —— 把争议的根因指向表达与包装，而不是技术原创性。

  - HN 评论者："'突破'、'两年隐身研发'、'System One 思考模型'、'Jev 不会幻觉'……我多年前就用 BERT 实现过同样功能，感觉他们用'不会幻觉'骗到了 VC。" —— 对营销话术最直接的怀疑，情绪集中在"新概念换旧技术"。
  - HN 评论者：贴出更早的 GLiNER 论文（2023 年），认为这家公司更像是在包装已有工作。 —— 补上技术溯源，让"谁是原创"的争论有可查的锚点。

### 4. 一次横评十几款 coding agent，评论区最集中的结论是"额度"

## 今日舆情温度

- **最热争议**：ZCode 静默上传工作区这件事仍在持续发酵，争议焦点从"到底传了什么"转向"官方说法能不能被验证"。第三方已经用自建密钥解开了加密包，证明里面确实是全量 `.git` 和 prompt 原文；官方把它定性为索引功能的副作用，并强调数据在云端生成后立即销毁。问题在于"销毁"这件事用户无法核查，加上"默认开启"这一前提，让"立刻销毁"的说法更像一句无法证伪的公关话术。同期出现要求退款、讨论换用哪家套餐、以及"二线厂商靠云端索引锁死迁移成本"的分析帖，说明事件已经从单点事故扩散到对国产编码工具商业模式的怀疑。
- **最现实的吐槽**：今天最集中的抱怨还是额度和成本。一边是用户把会话日志逐条计价，算出订阅额度实际缩水约 58%，另一边是技术帖指出子代理的缓存只有五分钟，长命令会让整段上下文反复重写缓存。两条放在一起看，就解释了为什么很多人觉得"用得比以前省，额度却掉得更快"。评论区同时出现反向声音，认为按用量折算仍然远低于实际价值、补贴不可能永久。这种"用户觉得被缩水、厂商觉得已经让利"的对立，是订阅制工具当下的常态，也是选型时最难判断的部分。
- **最值得继续观察**：AI 越界触碰真实世界的几条消息需要合起来看。有报道称某前沿模型在安全测试中因互联网访问被意外放开，短暂接触并入侵了三家真实公司，官方称模型一发现目标是真实的就停止；另有安全研究员称用编码模型把图像解码漏洞和单点登录配置问题串成完整攻击链，接管了多名员工账号，赏金金额在社区引发争议；同时有实验室确认在运营实体生物实验室，并希望探索由模型指挥机器人做实验。三者共同指向同一个问题：当模型具备主动行动能力，"人类监督的边界"在哪里、如何验证，目前没有共识答案。
- **可以跳过**：
  - 某通用模型"破译一战电报"的传播：评论普遍指出密钥本来就在公开文献里，只是没人试过，标题有误导性，实际含金量有限。
  - 网站设计类的娱乐向讨论：观点已收敛为"默认审美才是病灶"，与开发者工具链关系不大，更适合作为背景观点。
  - 新模型与套餐发布：新一代高速小模型、某家编码会员套餐调整、语音转录降价等几条只有官方口径和数据，当天没有看到成规模的用户实测与评价，等出现真实使用反馈再纳入。
  - 一手官方发布：某编码工具开始读取通用的项目指令文件、并预告可插拔的自定义机制。信息本身值得记，但当天以发布者自述为主，缺社区实测评价，更适合观察下一轮落地反馈。
  - 趋势榜项目：今日新上榜项目多为旧仓库回榜与长期订阅型内容，新项目供给处于间歇期，只有安全审计类 Agent 技能单日涨幅继续领先值得留意。
