## 1. AI 普及之后，应该把所有 Electron 重写为 native

作者认为 Electron 应用开久了内存占用只涨不降、界面越来越卡；既然 AI 已经降低了写代码的成本，那第一件事就该把这类应用全部重写为原生应用，“大不了 macOS 和 Windows 各写一套”。这是典型的“旧技术债是否值得重算”的命题，评论区没有停留在站队，而是给出了真实的迁移成本。

- **2 楼 sentinelK（❤3）**：Electron 的价值在于 UI 与硬件机制解耦，业务 UI 和底层可以完全独立、逻辑通用；换成 native 就等于放弃各平台的原生 UI 机制，结果不只是代码量翻倍。
- **55 楼 nullyouraise（❤2）**：他真做过才知道。他用 Rust + GPUI 写了 Agent 与终端二合一的 GUI，迭代三个月后说“现在我已经想用 Electron 重写了”，原因是 Rust 编译慢、没有 DevTools 给 Agent 做 UI 调试，npm 生态的现成方案也拿不到。
- **21 楼 Chuckle（❤1）**：写代码的成本一直不是大头，管理成本会起飞的。

值得关注：这条讨论打破了“AI 让重写变便宜”的流行推论——节省下来的是打字，而不是维护成本。
