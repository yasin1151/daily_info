**① 要闻｜Codex 负责人 Tibo：28 天每日改进，做不到就全额重置用量额度**

Codex 负责人 Tibo 在 X 上公开立下承诺：未来 28 天内，团队每天要么给多数 Codex 和 Work 用户上线一项"有实际价值的明显改进"，要么就完整重置一次用量额度。他此前已表态团队方向已锁定——只做简化、提升用量效率、新功能和新模型，理由是用户反馈非常明确：产品要更简单。

- 核心变化：把"改进"从季度路线图变成了日更制的硬承诺，并且拿用量额度作为违约赔付。
- 影响：这是 OpenAI 在编程 Agent 战场上少见的高频、可验证承诺，说明 Codex 正被 Claude Code、DeepSeek Harness 等对手挤压到必须靠速度和额度留住用户；对开发者来说短期大概率能看到额度放宽。

**② 开发生态｜DeepSeek Harness 加 Claude Code Mods 兼容层，组成员崔添翼回应：这是"子集验证"，不是真兼容**

DeepSeek Harness 发布 v0.2.1-alpha.1 预发布版，新增实验性 Claude Code Mods 兼容层。官方发布说明写得很直白：这一阶段的目的只是**验证** Claude Code Mods API 的能力大致是 Harness 插件能力的"一个子集"，而不是给用户提供实际完整的兼容性。

兼容层作者、Harness 组成员崔添翼在知乎回应（半原话）：该兼容层属于 alpha 阶段的实验性功能，"尚有很多不完善之处，不能保证百分之百兼容"，目前无法让所有 Claude Code Mods 无缝运行；但"从技术上看，若这是值得投入的目标，未来有可能做到"。他同时强调"一切皆插件"是 Harness 立项之初就确立的核心理念，"并非被迫或模仿别人"，其意义有三：用插件和社区满足多样化需求（创造模式已允许 Agent 自己编写并安装插件）、用插件化满足不同行业企业部署、以及推进 Agent 自进化命题——团队正在招相关研究员。

- 核心变化：把生态互操作做成了一次架构验证实验，并公开承认"不兼容"。
- 影响：这句话的潜台词是"我们的插件体系是超集"——是最直接的生态宣示，也意味着 Claude Code 的 Mods 生态可能被反向吸收。第三方 Mods 作者现阶段不要期待即插即用。
- 原文：https://www.zhihu.com/question/2089740005770008568/answer/2090104616759325588
- 版本说明：https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.2.1-alpha.1

**③ 行业动态｜马斯克确认 SpaceXAI 将更名为 SpaceXSI，"AI"这个词在美国官方语境里要被换掉**

马斯克在 X 上回复网友关于 SpaceXAI 是否会更名为 SpaceXSI 的提问时明确说"会的，我们会做出改变"，随后发帖称 SpaceX 是一家超级智能公司。背景是特朗普此前签署行政令，要求美国行政部门在官方通信、公开声明等文件中用 "Super Intelligence"（SI）替代 "Artificial Intelligence"（AI）。截至目前，SpaceXAI 的 X 账号和网站尚未改名，马斯克也没给时间表。

- 核心变化：一个纯命名/话语层面的动作，但发生在美国官方文件改词的政策背景下。
- 影响：值得关注的不是改名本身，而是"AI → SI"这套话术开始被企业跟进。它会重塑监管与舆论讨论的框架（超级智能=需要更强管制的叙事），也给后续合规、投资叙事埋下变量。目前马斯克只是口头表态，落地还不确定。
- 原文：https://x.com/elonmusk/status/2106665679361618173
- 政策原文：https://www.whitehouse.gov/presidential-actions/2026/09/inaugurating-the-era-of-super-intelligence/

**④ 前瞻与传闻｜Nvidia 投资 8 亿美元的 Reflection 即将发首个开放权重模型，目标是对标中国开源**

据 Axios 报道，获 Nvidia 8 亿美元投资的 AI 初创公司 Reflection 正准备近期发布首个开放权重模型，公司拒绝置评，发布时间与性能均未公布。报道称该模型初期会落后于美国最先进模型，但**能与中国的顶尖开放权重模型竞争**。Reflection 更大的野心是"AI 工厂"：企业或政府把自有数据、Reflection 模型和自有算力组合起来，构建低成本的定制 AI 系统。今年 3 月，它已与韩国新世界集团签谅解备忘录，计划在韩国建一座 250 兆瓦、跑 Reflection 模型 + Nvidia 芯片的 AI 工厂。

- 核心变化：美国资本开始正面回应"中国开源模型已领先"的现实，用开放权重作为竞争手段。
- 影响：如果属实，开放权重赛道上会多一个 Nvidia 系重量级玩家，"美国闭源 vs 中国开源"的简单二分将失效。但注意这仍是传闻级信息，无时间表、无 benchmark，暂不可当既成事实看待。
- 原文：https://www.axios.com/2026/10/04/reflection-open-weight-ai
