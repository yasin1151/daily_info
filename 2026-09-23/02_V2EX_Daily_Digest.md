**2. 给极空间 NAS 写了个零配置 CLI + MCP：不填密码不配 SSH，让 AI 直接管 NAS**
摘要：极空间没有官方 CLI 和公开 API，作者的 zspace-cli 选择"寄生"在已登录的桌面客户端上——直接读客户端登录态、走它本地的 127.0.0.1:13579 代理，因此不用密码、不用 SSH、不用 DDNS/端口转发，客户端开着就能用。提供完整 CLI + Python SDK + MCP server（Claude/Cursor 可直连），并附 8 个跨 NAS 的整理 Agent Skill（照片/音乐/影视/重复文件/备份审计），人工确认后再由 Agent 执行。工程细节最实：大文件上传是逆向桌面客户端的分片协议（uuid 会话 + 2MB 分片）实现的，因为本地代理对单请求体积有上限、普通做法直接 413；680MB 视频往返过 MD5 校验，中文文件名全链路正常。CI 全 mock，没有极空间也能贡献代码。
