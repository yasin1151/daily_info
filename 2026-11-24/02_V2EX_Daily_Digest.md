## 2. 「做了套给 AI CLI 用的 iTerm2 配置，先解决日志太吵」（0 回复）

**摘要**：作者把用了五年的终端配置重做了一遍，理由是需求变了：以前一条命令跑几秒、输出十几行，终端是执行窗口；现在一个 agent 任务跑几分钟、输出几百行，终端变成监控面板。改动全部落在 iTerm2 这一层而不做 agent 插件——Triggers 给 ERROR/WARN/SUCCESS 关键词染色（只标词不涂整行）、Shift+Enter 换行不提交（写给 AI 的多行 prompt 不用先开编辑器）、Smart Selection 让 `path:line`、Git SHA、`localhost:port` 支持 Cmd-click 直接开编辑器 / 跑 `git show` / 开浏览器。

**为什么值得看**：他对「为什么不做插件」的解释是全文最有价值的一句——Claude Code 和 Codex 各有各的输出格式，写解析插件等于给每个工具写一遍还得跟着升级；放在终端层则所有输出一视同仁。代价是只能做正则和键映射、理解不了语义，且 Triggers 只对新开的 tab 生效（装完不 Cmd+T 会以为没生效）。

🔗 https://www.v2ex.com/t/1259258
