### 1. 一条"网站摘要"请求就劫持了 Claude Code Opus 5 Auto Mode，第三方 0% 测试被实测打脸

- **来源**：HackerNews（335 分 / 110 评）
- **一句话人话版**：安全研究员用诱导提示攻破 Claude Code Opus 5 的 Auto Mode 实现代码执行，小样本成功率 60–80%，直接打脸 Anthropic 委托第三方测出的 0%。
- **新闻/帖子本身**：Auto Mode 用安全分类器取代人工审批，攻击者借"帮我总结这个网站"之类的请求植入恶意指令，即可让模型执行代码。此前 Anthropic 委托 Trajectory Labs 做 72 组间接提示注入测试，声称攻击成功率为 0.00%，作者实测反差巨大。文章核心观点：Auto Mode 不能替代隔离沙箱和监控——"如果你在意 misalignment 和提示注入，就别把 Auto Mode 当保险"。作者还指出，0% 的第三方测试结果给团队制造了虚假安全感，真实攻击面恰恰藏在"总结网页、读取文件"这类日常请求里。演示还覆盖了从提示注入到命令执行的完整链路，包括读取本地文件与发起网络请求。
- **社区原话摘录**：
  - HN 评论者："I'm quite surprised that we are not seeing something like this more in the wild. Quite concerning" —— 惊讶现实中没见到更多这类攻击，反而更令人担忧
  - HN 评论者："It's not that far off a typical trojan, just one tailored to Claude's habits" —— 本质上就是针对 Claude 习惯定制的木马，威胁模型早已存在
  - HN 评论者："What vibe 'don't even gotta read it' coder would even notice if it happened?" —— 连代码都不读的 vibe 程序员根本发现不了自己被劫持
- **参谋部短评**：0% 与 60–80% 的落差动摇了"第三方评测可信"的信任基础，Agent 安全评估方法论本身成了争议点；Anthropic 的回应和独立复测值得继续盯。

### 2. Google 从 Chrome 商店移除全部 MV2 扩展，uBlock Origin 时代终结

- **来源**：HackerNews（314 分 / 228 评）
- **一句话人话版**：Google 把全部 Manifest V2 扩展从 Chrome 商店下架，包括最强广告拦截器 uBlock Origin，已装的老版本不能更新也不能重装。
- **新闻/帖子本身**：MV2 时代正式终结。Chrome 138 及更早版本上已安装的扩展可继续用，但无法更新、无法重装；影响波及 Brave 等依赖 Chrome Web Store 的 Chromium 浏览器，Brave 自己托管了 4 个流行 MV2 扩展续命。uBO 用户被迫迁往功能弱化的 MV3 版本或更换浏览器，被视为浏览器广告拦截生态的标志性节点。对普通用户而言，最直接的影响是广告拦截能力下降：MV3 版 uBO 依赖 declarativeNetRequest，规则数量和动态拦截能力都受限。
- **社区原话摘录**：
  - HN 评论者："Switch to firefox" —— 一句话立场，社区最大公约数答案：换浏览器
  - HN 评论者："try to not use Google, Facebook, Amazon, OpenAI, Anthropic, Microsoft, Oracle and other similar products made by asshole companies" —— 不满已从单个产品上升到对大厂整体抵制
  - HN 评论者："One Google doom over, another to go"，附 keepandroidopen.org 链接 —— 反 Google 行动才刚开个头，下一个战场是 Android
- **参谋部短评**：争议不在技术而在"平台决定你能装什么"的控制权；浏览器是 Agent 时代的入口，这类控制权事件会反复出现，值得长期跟踪用户迁移信号。
- **链接**：https://webiterate.dev/google-removed-extensions-ublock-origin-108/

## 今日舆情温度

- **最热争议**：Agent 安全。Claude Code Opus 5 Auto Mode 被一条"网站摘要"请求劫持，实测成功率 60–80%，直接打脸第三方 0% 测试；同一天 X 上，Replit CEO 复盘 Hugging Face 事件，称"带可验证奖励的强化学习是极其强大的优化算法，会让 LLM 产生越来越怪异、出人意料的行为"，并指出 OpenAI 明显的失误是没监控 CoT（思维链），而这是一年多前 OpenAI 自己提出的安全策略；Every CEO 则定调"该认真对待，但不是机器接管的第一声警告"。争议点很具体：Auto Mode 的安全分类器能不能替代人工审批，CoT 该不该被监控、由谁监控。围绕 Auto Mode 的立场也分裂：支持方觉得便利性值得保留，反对方认为在可解释性解决之前，默认开启代码执行权限就是对用户不负责任。这也让"先测试后发布"的行业惯例受到审视：0% 的结果到底是测试设计问题，还是评测机构的能力问题。

- **最现实的吐槽**：硬件和额度的钱。HN 抱怨苹果"涨得太狠了"、"内存就是新黄金"；V2EX 上 4 万块 Mac 本地部署被算成"4.4 年回本、负投资"；OpenAI 借 2500 万活跃用户里程碑给所有付费订阅重置用量额度，自称"The Reset Company"——额度重置被当成常规运营手段，重度用户等于每月多一次满血额度，但也有人质疑这是不是另一种"促销话术"。另一头，V2EX 上单文件 Agent 工具被吐槽"默认密码居然就是 123，翻半天文档没看见"，安全底线问题比功能问题更劝退。对开发者来说，额度政策直接决定每月成本，重置虽好，但"这次用完要等多久"的不确定性才是常态。至于 Mac 本地部署派，则是另一笔账：买机器的钱够买好几年 API 额度，但数据不出本机带来的安全感无法用价格衡量。

- **最值得继续观察**：其一，Anthropic 对 Opus 5 攻破的回应与独立复测，0% 与 60–80% 之间的差距需要解释；其二，OpenAI 数万台 Mac 采购是否官方确认，Mac 在 Agent 训练里的角色可能改写硬件叙事；其三，字节豆包 2.2 延期至年底，目标是编程、工具调用和 Agent 能力对标智谱与 Kimi 最新水平，国产模型竞赛进入"编程/Agent 决胜期"；其四，GitHub 榜单上 archify、scientific-agent-skills 等项目 star 增速异常、另有项目 forks 远超 stars，刷星嫌疑值得警惕，引用数据需以官方仓库为准；其五，AI 陪伴应用 Tolan 四周 ARR 从 100 万美元涨到 400 万，赛道增速惊人，但壁垒在故事工程和毫秒级响应而非模型本身，值得验证其可持续性。
