**1｜Anthropic 设立公益基金，先投入公司 5% 股份**
Anthropic 成立了全资实体 Anthropic Public Benefit Fund，经股东批准后先注入公司 5% 股份；此后公司估值每比基准上涨 50%，董事会可再追加 2%。加上联合创始人承诺捐出的 80% 股权，以及约半数员工参与的配比捐赠计划，合计约 20% 的公司股份将用于公益。基金采用 LLC 而非 501(c)(3) 形式，所持股权不用于政治游说和捐赠；资金去向包括向非营利组织大额捐赠、向特定人群直接分配，以及应对 AI 对劳动力市场的冲击（此前已为此承诺 2 亿美元）。
**影响**：这是头部 AI 公司首次把"随估值增长的股权"制度化地转为公益，相当于给"AI 收益如何回流社会"提供了一个可复制的结构模板；但治理细则和估值基准仍未公布，实际约束力还要看后续披露。
https://www.anthropic.com/news/public-benefit-fund

**2｜Wolf 估算：开源模型的训练算力累计价值已近 10 亿美元**
Hugging Face 联合创始人 Thomas Wolf 统计了约 35 家机构（Meta、NVIDIA、阿里、DeepSeek、Moonshot、Mistral 等）在 HF Hub 上开源的 72 个模型家族，按当前 GPU 租价折算训练算力，中心估值约 9.5 亿美元，而 2023 年底还不到 4000 万美元。其中约一半依据机构自公布的算力数据，其余为推算；他明确表示这是下限，未计入约 90 万个社区微调、失败的训练运行、团队开支和数据集。
**影响**：这个数字把"开源模型是公共品"从口号变成了可计价的账本——约 10 亿美元的算力被免费释放。对成本敏感的团队来说，这直接说明了为什么"从开源基座起步"仍是性价比最高的路径；同时也提示，开源生态的真实投入被严重低估。
https://thomwolf-hub-dollars.static.hf.space

**3｜OpenAI API 短暂出现 3 个新模型 ID：aurora-red/green/blue-alpha**
多位 X 用户发现 OpenAI API 中短暂出现 aurora-red-alpha、aurora-green-alpha、aurora-blue-alpha 三个模型 ID，随后被移除。TestingCatalog 记录了这次出现和消失；用户 Lumina 称在 Arena 中实际遇到了 red 和 green 版本，按猫咪提示词生成图像，判断三者都是图像生成模型，但 blue 版本尚未出现。
**影响**：三个平行代号 + Arena 盲测的组合，通常指向同一底座的多个变体（风格/参数档位）在对比测试，也意味着图像生成线在为新版本做公开前的偏好收集。OpenAI 官方未确认任何信息，属传闻级，但 API ID 泄露历来是发布前最可靠的先行信号之一。
https://x.com/testingcatalog/status/2111724606927028578

**4｜FT：Anthropic 正与律所商讨"AI 谈判规范"**
据《金融时报》，Anthropic 正与律所等法律机构磋商，为将来替用户砍价、处理纠纷、谈薪资的 AI Agent 制定谈判行为规范，核心问题是：Agent 如何在代表用户利益的同时兼顾公平结果。讨论涉及 Agent 谈判时应多大程度寻求人类确认、面对其他 AI 对手时保持多高警惕，甚至探讨让用户签署文件确认委托事项和全部规则。
**影响**：这是把 Agent 从"执行工具"推进到"代理签约方"时必须先解决的问题——一旦 Agent 代表你出价，责任归属、授权边界、和对方 AI 博弈的伦理都需要成文规则。Anthropic 提前找律师定调，说明这类"代理型 Agent"的商用落地已进入合规设计阶段，而非仅是 demo。
https://the-decoder.com/anthropic-consults-law-firms-to-set-fair-negotiation-norms-before-ai-agents-start-cutting-deals/
