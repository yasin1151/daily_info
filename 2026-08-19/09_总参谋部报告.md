### 1. Cursor 上线代码托管 Origin 叫板 GitHub，评论区先吵"谁能赢"

- **一句话人话版**：Cursor 推出自己的代码托管服务 Origin，仓库、PR、代码浏览都有，还支持与 GitHub 双向同步，等于直接冲进 GitHub 的地盘。

- **社区原话摘录**：
  - HN 评论者："感觉更像是 AI PR 数量激增带来的负载问题，而非产品本身质量下降……但我不确定替代者长期能赢 GitHub。" —— 认为 Origin 的动机是 AI 生成 PR 挤爆 GitHub，但长期胜负存疑。

- **参谋部短评**：编码 Agent 厂商自建托管加部署闭环，是本周最值得盯的格局变化；重点看 Origin 正式版定价与 GitHub 的反制动作，以及"AI 原生托管"到底比 GitHub 强在哪。

### 5. 内存价格 12 个月暴涨 500%，128GB DDR5 卖到 3399 美元

- **来源**：HackerNews（422 赞 / 44 评论）
- **一句话人话版**：DRAM 价格一年涨五倍，128GB DDR5 现价 3399 美元，AI 服务器挤占产能是主因之一。
- **新闻/帖子本身**：Tom's Hardware 报道 DRAM 价格一年内上涨 500%，达到有记录以来最低价的 10 倍。原因包括 2023 年供给过剩后厂商集体停止扩产、AI 服务器挤占产能，以及寡头市场历史上多次被指控合谋。内存涨价直接推高服务器、笔记本成本，并会传导到云厂商定价，对做 AI 应用和自建集群的团队都是实打实的成本压力。
- **社区原话摘录**：
  - HN 评论者："其实是两者都有。DRAM 是典型的繁荣-萧条周期，2023 年严重过剩，厂商在那之前就决定不再扩产能，只为在现有产线上回本。" —— 老玩家视角：这轮涨价是周期底部停产的必然结果，不全是 AI 的锅。
  - HN 评论者："CXMT 几乎肯定会吃掉 DDR5 市场（虽然一两年内改变不了什么）。" —— 国产内存被寄予破局厚望，但短期产能爬坡赶不上涨价窗口。
- **参谋部短评**：内存是 AI 基建的"石油"，涨价会传导到云定价与自建集群成本；和今天的额度吐槽、模型价格战放一起，成本压力是本周贯穿性主线。
