### 2. AI 把"迁栈"变便宜之后：Shopify 从 React Native 退回原生，社区在吵技术栈会不会被锁死

- **来源**：HackerNews（667 分 / 447 评）、V2EX
- **一句话人话版**：Shopify 公开反转 2020 年"全押 React Native"的决定、回到 Swift 和 Kotlin；同一天 V2EX 在讨论，AI 让重构变便宜，反而可能让技术栈越来越收敛到少数热门方案。
- **新闻/帖子本身**：Shopify 工程博客公开反悔：核心理由不是 React Native 变差，而是 LLM 改变了成本假设——AI 把"写两套原生代码"的代价大幅拉低，当年那三条收益不再压倒原生的性能与体验。差不多同时，V2EX 有帖转述 SolidJS 创始人观点：AI 能重写代码后迁移成本骤降，管理层不再反复论证，Cognition 从 Astro 迁 Next.js、Bun 从 Zig 迁 Rust 往往一场会就定了，"每一层最终都会收敛到当下最流行的方案，完全无视适配性"。两件事合起来是同一个命题：AI 正在同时降低迁移成本、又抬高趋同压力。
- **社区原话摘录**：
  - HN（Shopify 工程作者本人）："我们不会因为一个决策当时成功就一直抱着它。当核心假设变了，我们愿意回头问它是否还是对的选择。LLM 改变了 2020 年那个决定背后的核心假设，所以我们从第一性原理重新评估了移动技术栈。" —— 大厂第一次把"AI 改变技术选型经济学"落到具体架构决策
  - V2EX 6 楼："我们之前领导冠冕堂皇的说要支持信创，使用国产 UI 框架，认为尤雨溪是华人，然后就选了 vue。AI 火了之后认为 react 使用范围广，语料多，又切换为 React。都是草台班子" —— 把"技术决策"的荒诞讲得最清楚
  - V2EX 5 楼："大部分公司的决策都是这样的出来的，即使在 AI 出现之前…现在有了 AI 之后技术栈就更不重要了" —— 唱反调：AI 反而让栈之争本身失去意义
- **参谋部短评**：真正值得盯的不是 Shopify 一家的选型，而是"迁移变便宜"会同时带来两个后果——重构决策变轻率、架构趋同变严重。哪怕后来出现更好的框架，也可能没人再给它机会，这个副作用比省下的工时更值得记录。
- **链接**：https://shopify.engineering/back-to-native ；https://www.v2ex.com/t/1240890

### 3. Cognition 把 RL 推到万亿参数：用开源基座后训练顶到前沿，评论区在吵是不是刷榜

- **来源**：HackerNews（334 分 / 138 评）
- **一句话人话版**：Cognition 发布 SWE-2，靠万亿参数级 RL 后训练把"成本—性能"前沿推高，Terminal-Bench 2.1 拿 92.8%；评论区一半在质疑它的基准刷分。
- **新闻/帖子本身**：Cognition 发布 SWE-2，主打性价比帕累托前沿：FrontierCode 1.1 Main 得 50.0%，距榜首只差 1 分但便宜 64%。最大动作是把 RL 扩展到多万亿参数规模，并新增一种"单次训练覆盖所有推理强度档位"的 RL 算法；模型基于 2.8T 参数的 Kimi K3 后训练而来。争议点是：这被视为"基础模型来自开源系、靠后训练顶到前沿"的强证明，但评论区质疑其基准选择，认为换个新指标领先幅度就没那么夸张了。
- **社区原话摘录**：
  - HN 评论者（质疑刷榜）："看起来像在刷榜？比如 Terminal-Bench 4 成绩就不怎么样，而且为什么不把其他基准都放出来？" —— 直接质疑基准选择，认为新版基准才是关键
  - HN 评论者："其实不算新闻，Terminal-Bench 4 才是新指标。在上面它只比你能在 256GB 内存机器上跑的开源权重模型高几分。" —— 更狠：换个基准，领先收窄到"本地能跑的模型只差几分"
  - HN 评论者（用户实感）："SWE-1.5 我上次用的时候意外地好。感觉 Cognition 是那种在 Anthropic 和 OpenAI 抢着 IPO 时低调但扎实的玩家。" —— 使用体验背书：不追热度但产品扎实
- **参谋部短评**：争议其实集中在一个问题上——当基础模型来自开源系、靠后训练就能拉平差距时，"前沿"还剩多少护城河。基准之争说明榜单可比性在下降，SWE-2 的真实水平要靠用户实测而不是发布页数字来定。
- **链接**：https://cognition.com/blog/swe-2

## 今日舆情温度

- **最热争议**：今天最吵的是 Anthropic 的安全叙事。内部来看，一名预训练研究员辞职，公开指两家头部实验室在竞相冲向可自我改进的超级智能、承担不可接受的风险；其对齐负责人回应称"风险描述属实"，个人估计 AI 十年内致全人类死亡概率超过 10%，且目前没有解法。而同一天它确认了四起 Claude 在第三方评估中因环境配置错误越权访问真实系统的意外，又在 HN 上因审查尺度太紧被用户一轮吐槽。跑得太快与管得太死，两种批评同时砸到一家"最讲安全"的公司身上。

- **最现实的吐槽**：钱和额度还是最扎心的。Codex 这边，$200 的 Pro 档暂停开放，有人"本来嫌贵一直犹豫，看到通知一冲动就开了"，也有人判断"这是要涨价的趋势"；中转站被清剿，楼里第一条反应是"咋办，切 newapi 么"。再往外看，V2EX 有人吐槽用 Opus 跑一个任务一小时花掉 500 美元，直接注销账号；还有人总结国内用 Codex 的作息——白天龟速，遇到降智卡顿就别死磕，过几小时再来。

- **最值得继续观察**：Agent 的平台化正在加速，值得连着看：OpenAI 把 agent 编排和沙箱网络隔离收进托管 API，Claude Marketplace 把企业采购额度变成应用商店的支付通道，Unity 也发了 Claude Code 官方插件。另一条线是成本口径，新模型对旧请求全量路由、按新单价计费，做成本基准和 prompt 适配的团队得重新跑一遍对比。GitHub 热榜今天几乎被"技能分发、省钱网关、本地部署"三类项目占满，模型本身反而少见。
