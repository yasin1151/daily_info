### 2. 实测对照：Grok Build 周额度悄悄缩水约 48%

- **来源**：V2EX
- **一句话人话版**：用户用正价订阅做同条件对照实验，算出 Grok Build 本周新增 token 只有上周的 52%，怀疑周池被减半。
- **新闻/帖子本身**：一位用户用 SuperGrok 正价订阅做同条件对照实验：相同模型、CLI 版本、缓存比例、并发设置，本周实测新增 token 只有上周的 51.998%，推定 Grok Build 周池被减半。这是社区少见的"用数据锤厂商"操作——不靠截图吐槽，直接控制变量跑两周对比。对 API 重度用户是重要信号：订阅额度缩水往往不会发公告，只能靠用户自己发现。
- **社区原话摘录**：
  - V2EX 1 楼：贴出自己 grok-4.6 中转用量明细（1,318 次调用、输入 166M tokens、合计 104.21 美元），问"这样算不算缩水" —— 摆出真实成本账，说明重度用户对额度变化极其敏感。
  - V2EX 2 楼："grok4.6 发布第一周有双倍用量" —— 给出另一种解释：首周双倍促销到期后回归正常，缩水未必是暗改。
- **参谋部短评**：单用户双周对照不是铁证，但"额度缩水不公告"的怀疑本身值得盯。若更多用户复现，可能发酵成新一轮订阅信任问题；也提醒大家留意自己订阅的实际消耗。

### 3. 开源小模型 30 分钟搞定逆向工程，还主动回头纠错

- **来源**：HackerNews（159 赞 / 80+ 评论）
- **一句话人话版**：作者把商业应用授权校验的逆向任务交给 Qwen 3.8 27B 本地模型，它半小时完成，还发现并修正了自己的校验错误。
- **新闻/帖子本身**：作者把"最难的单机任务"交给 Qwen 3.8 27B——逆向一款商业应用的授权校验并恢复密钥。模型不仅还原出能通过签名校验的 key，还发现二进制内部完整性哈希不匹配，主动回头重做直到完全一致。评论区多位用户分享本地部署体验：RTX 4090+3070 跑账单/合同整理、64GB Mac M3 Pro 上用 opencode 写后台 UI，表现都不错。开源本地模型在真实逆向任务上展示出"发现问题—自我纠错"的闭环能力，是今天 HN 最热话题。
- **社区原话摘录**：
  - HN 评论者："首次恢复的 key 能过签名校验，但二进制算的完整性哈希对不上——换成大多数模型早就交差收工了，Qwen 没有，它指出不匹配、回头重做直到值完全吻合" —— 强调模型主动纠错而非一次成型，这是与"交差型"模型的本质差别。
  - HN 评论者（质疑）："你终端截图里显示的明明是 Claude 订阅的 opus-4.6-medium，不是 Qwen？" —— 直接质疑实验截图真实性，评论区为此吵起来。
  - HN 评论者（反驳）："有明确 true/false 判定标准的任务恰恰不是'最难的'，这类可测试任务正是 AI 辅助编码收益最大的地方" —— 认为标题有夸张成分，可验证任务本就不算难，但收益确实实在。
- **参谋部短评**：质疑与实测并存，说明社区对"开源模型超神"叙事已经学会先查证。真正值得继续盯的是本地模型的自我纠错闭环，这比单点任务成功更能说明模型能力变化。
- **链接**：https://www.xda-developers.com/qwen-3-8-27b-reverse-engineering-job-frontier-model/ ；https://news.ycombinator.com/item?id=49407507

## 今日舆情温度

- **最热争议**：今天的主战场是编码 agent 的额度：Codex 官方承认三处烧量 bug 并全量重置、部分用户缓存命中率下滑导致额度掉得快、有人 100 个 subagent 并发把 pro20x 烧穿、Grok Build 周额度被实测缩水 48%。社区整体情绪是"额度敏感 + 信任脆弱"：对官方公告先算时区账，对缩水先做对照实验，对"降智"直接开贴质疑。围绕"额度到底怎么算的"和"模型是不是悄悄降智"，支持派、理性派、吐槽派都能拿出具体证据，是近期少见的全民参与式技术争议。
- **最现实的吐槽**：重度用户最疼的几件事今天全齐了：额度监控成了日常（有人专门做了托盘图标随额度变色的监控工具）、重置卡用户直呼"刚用重置卡就重置，坑爹"、Grok 缩水只能靠用户自己两周对照实验发现、Claude Code 显示数字变一下就被怀疑降智。吐槽背后是同一个事实：订阅制额度对重度用户是硬约束，任何风吹草动都直接换算成钱，厂商的信任成本正在变高。
- **最值得继续观察**：一是 Codex 修复落地后额度消耗是否恢复正常、缓存命中率调查结论；二是 opencode 上神秘模型 Ox Alpha Free（疑似 GLM 系）被用户拿来 review 代码、发现了 Opus 4.6 漏掉的 bug，但次日就用不了了，限时下架后会不会回归；三是 Anthropic 首次放开插件生态（社区插件市场 + 新产品 Claude Cowork 曝光），Agent 插件"App Store"化趋势；四是微软 CTO 公开背书 MCP 和企业内部"统一 Agent 协议"，协议层的生态信号值得持续跟踪。
