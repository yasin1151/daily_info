- **新闻/帖子本身**：博主连续一个月重度使用 DeepSeek 4.1 Flash 跑十几个项目，结论是能力接近前沿、价格低几个数量级——10 美元/月的订阅基本无限用，单次会话极少超过 1 美元，单次任务成本从 1 美元降到 0.003 美元，彻底改变了他“敢不敢随手起任务”的心理阈值。他的技术解释是 KV cache 相比自家上一代缩小约 437 倍，把长会话成本压在 GPU 显存这个最大开销项上。他的实际工作流是日常规划和执行交给 4.1 Flash，关键任务才拉一次前沿模型做代码审查，且明说“更多是为了换双眼睛看问题，不是质量差距”。
- **社区原话摘录**：

- **参谋部短评**：值得盯的是“够用即改变工作方式”这条：阈值从 1 美元降到 0.003 美元，开发者的行为模式会变。争议点不在跑分，而在前沿厂商为何无动于衷。

### 4. 一个 prompt 加六小时：前沿模型把《看不见的城市》做成可视化，成本差距成焦点
- **来源**：Hacker News（336 分 / 173 评论）
- **一句话人话版**：作者用同一个 prompt、给 6 小时预算，让两个模型把卡尔维诺的 55 座城市做成 three.js 可视化，成品和花费差距拉得很大。
- **新闻/帖子本身**：作者的 prompt 是“用 three.js 做出《看不见的城市》全部 55 座城市的可视化，别问问题，这是一次性任务，你有 6 小时，用到它成为杰作为止”，分别交给两个前沿模型。一个用 53 分钟、约 10 美元完成，但混入大量 AI 设计噪音和无用注释；另一个号称用了 6 小时，实际只花 1 小时 25 分钟（6 个并行子代理折算约 7 agent-hours）、约 74 美元，成品让作者“看呆了”。他由此判断设计领域会像编码一样被 AI 大规模渗透，并自问“那么我在交互媒体创作里的位置是什么”。
- **社区原话摘录**：
  - HN 评论者：“同一个 prompt，74 美元 vs 10 美元 vs 25 美元。有意思的不是质量，而是每美元能买到多少产出，比如并行跑 6 个子代理。” —— 把讨论从“哪个模型强”拉回单位成本的产出效率。
  - HN 评论者：随机点开第一座城市就看到开头写“到达时你会为它的桥而欣喜，每座都不同”，结果“模型做的城里总计大概五座桥，其中三座根本没连任何东西，只是漂在河中间顺着水流走”。 —— 典型的“文字达标、语义不达标”失败案例。
  - HN 评论者：“如果你还没读过这本书，我劝你先别看这个可视化。读这本书的乐趣之一就是让脑中的画面自由生长。” —— 提醒：AI 生成物正在替代人的想象过程，这是另一种成本。
- **参谋部短评**：一次性 prompt + 长时预算这个范式值得继续关注，但两边都没解决“对不对”的问题：便宜的省在质量，贵的也可能做出漂在河里的桥。

### 5. Reddit 热帖：怎么保证编码 agent 一个文件都删不掉
- **来源**：Reddit（r/ClaudeCode，42 条评论）
- **一句话人话版**：一位长期只用网页版写代码的用户发帖问，有没有办法确保编码 agent 不能删任何东西，回帖给了一套按强弱排序的分层防护。
- **新闻/帖子本身**：楼主长期只用网页版写代码，听说编码 agent 会删库删盘，于是发帖问怎么确保它一个文件都删不掉——既想让它直接操作项目，又怕失控。高赞回答给出的分层防护是：最强的一层是版本控制加一份 agent 够不到的备份（远端或独立磁盘），这是唯一能覆盖项目内文件的防线；其次是开启内置沙箱，让 shell 只能写工作目录和临时目录；再把沙箱的“重试逃生口”关掉，不要在建立信任前使用绕过权限的模式；最彻底是把整个 agent 放进容器或虚拟机，只挂载项目。也有人提醒，只靠黑名单拦 rm 是最弱的一层。
- **社区原话摘录**：
  - Reddit 评论者（49 赞）：“把它放进 docker 容器，只给它访问你允许的文件。去掉它对主分支的写权限。” —— 最高分答案是“物理边界优先”，用容器而不是提示词约束 agent。
  - Reddit 评论者（17 赞）：“在黑名单里拦 rm 是最弱的一层。不敲 rm 也能删文件的方式太多了（find -delete、一行 Python 脚本、git clean、mv 覆盖）。” —— 点破“黑名单防删除”的常见错觉，并给出由强到弱的防护排序。
  - Reddit 评论者（7 赞）：“离线备份。如果你本来就没有，那你早就有麻烦了，只是还不知道。GitOps，一切都走 PR。” —— 把问题拉回工程纪律：agent 是放大器，不是新风险。
- **参谋部短评**：这条很实用——社区给出的顺序是“备份 > 沙箱 > 容器 > 黑名单”，顺序本身就是结论。想让 agent 直接碰生产文件的团队值得先看这帖。
- **链接**：https://www.reddit.com/r/ClaudeCode/comments/1wzacmn/how_to_ensure_claude_code_cant_delete_anything/

## 今日舆情温度

- **最热争议**：Anthropic 同日降价与封号潮同时出现，社区在两条线上都很吵。一边是 Haiku 5.5 平均成本降约 75%、Sonnet 5.5 缓存半价，官方口径是“更便宜”；另一边是用户实测 100k 上下文后计费跳档、600k 上下文烧掉 5 美元额度。两件事叠在一起，社区结论是：看单价没用，要看自己的任务落在哪个区间、以及账号能不能活到那时候。HN 那边则在争“性价比这么高为什么业界不慌”，有人给出的答案是前沿厂商在赌下一个能力台阶，价格战不是他们的赛道。

- **最现实的吐槽**：今天最集中的吐槽是“付了钱也保不住账号”。高价订阅用户参加官方送 credit 活动次日被封、刚续费退不回来；老用户说“5x 的号睡一觉起来就没了，封号没有必然逻辑”；还有人总结出应对思路是养一个看不出身份的账号。另一组吐槽围绕 agent 的权限与可靠性——同一件基本的事要反复批准，批准了还说做不了，有从业者干脆写“一年后我会用持久 agent，但这个大概会死”。这些都不是能力问题，而是产品的信任与运维问题。

- **最值得继续观察**：一是 Haiku 5.5 会被社区验证成“只适合当子代理”还是随工具链适配成为日常主力；二是 OpenAI 把最强模型拉平到全员可用、云端编码工具重新发布之后，订阅额度和使用体验怎么变；三是 agent 的组织形态正在收敛——有团队复盘后认为“人手一个个人 agent”难维护、寿命可能只有六个月，工作侧会走向“每个组织一个 agent”，这条判断如果成立，个人 agent 产品的护城河会很浅。

## 可以跳过

- 一批小模型与嵌入模型的发布通告：只有参数、延迟和跑分，缺少真实使用反馈，更适合留作背景资料。
- 端侧语音模型与本地照片编辑器的展示帖：讨论热闹，但多是“体积小、免费”的惊讶，几乎没有能判断长期可用性的使用体验，维护寿命才是关键问题。
- 平台把任务路由到第三方模型、办公软件新增 agent 功能之类的产品更新：信息以官方公告为主，评论区多为一次性围观。
- 科技文化与生活闲聊类热帖：讨论量大，但与 AI / 开发者工具的实际决策无关，只作情绪参照。
- 域名申请、签证政策类新闻：影响面大，但社区讨论偏向立场表达，与开发者工具链的当天动态关系不大。
