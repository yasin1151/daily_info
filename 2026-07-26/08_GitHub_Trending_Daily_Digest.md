## 1. aisuite：多模型生成式 AI Provider 统一接口

**项目简介**：`andrewyng/aisuite` 是一个 Python 项目，提供面向多个生成式 AI 服务商的统一调用接口。它的定位类似“轻量级 LLM provider 抽象层”，方便在不同模型供应商之间切换、测试和集成。

**为什么值得关注**：  
多模型、多供应商已经成为 AI 应用开发的常态。aisuite 的价值在于降低 provider 切换成本，适合用于 Agent、评测框架、内部工具、模型路由和 LLM 应用原型开发。项目由 Andrew Ng 相关账号维护，关注度和采用潜力都值得跟踪。

**语言**：Python  
**Stars**：15,213  
**今日新增 Stars**：75

## 2. bitchat：蓝牙 Mesh 聊天工具

**项目简介**：`permissionlesstech/bitchat` 是一个 Swift 项目，简介为 “bluetooth mesh chat, IRC vibes”，主打基于蓝牙 Mesh 的聊天体验，带有 IRC 风格的轻量通信形态。

**为什么值得关注**：
