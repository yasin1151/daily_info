
# 橘鸦AI早报 2026-09-13 摘要

**本期 7 条要闻，AI 圈最大焦点：Anthropic 与 OpenAI 罕见地在「放慢前沿」上达成一致表态。**

---

**1. Dario Amodei 发文呼吁「放慢前沿」，Altman 随即跟牌** ⭐ 本期最重要
Anthropic CEO 公开撰文《We must pace the frontier》，主张行业主动放慢模型能力提升，给安全/对齐/评估留出追赶时间。他给出的三步方案：引入「嵌入式评估者」（让第三方团队以接近正式员工的权限长期入驻，核查安全承诺、评估模型与训练管线）、民主国家协调、全球协调。理由是 AI 参与开发下一代 AI 造成的递归自我改进正在加速，近期 Agent 群体失调事件已显示「更强但同样失调的系统」可能带来严重网络安全风险。Sam Altman 随后表态 OpenAI 认同放慢，也会给予独立评估者类似员工的访问权限，具体安排待公布。
**为什么值得关注**：两大对手同时公开支持减速，是行业叙事的重要转向——但注意措辞是「pace（调整节奏）」而非「pause」，且嵌入式评估仍受法律、合同与客户隐私限制，实际约束力存疑。
🔗 https://darioamodei.com/post/we-must-pace-the-frontier ｜ https://x.com/sama/status/2098811563415150910

**2. Codex 负责人 Tibo：Astra 质量问题已修复，执行一次用量重置**
排查后确认三类问题：①部分为旧模型编写的 skills 触发过于频繁、甚至阻碍模型检查自身工作；②一个会导致提前停止或回复较旧消息的 opt-in 上下文管理实验（已停用，约 4000–5000 名用户受影响）；③若干配置不当、对长尾流量造成实测质量下降的引擎（已移除）。重置已于北京时间 12 日下午 4 点左右生效。
**为什么值得关注**：这是 Codex 侧近期质量口碑下滑的正面回应，且给出了具体归因（skills 与新上下文管理），对重度用户意味着体验应有明显改善——更一致的跟进执行、更好跟踪最新消息、任务推进中自查更完善。
🔗 https://x.com/thsottiaux/status/2098612714704891959

**3. Amp 宣布「自带模型/密钥即免费」，取消月付门槛**
不再需要月付订阅就能用 ChatGPT 订阅驱动 Amp；除 Enterprise 档外，所有用户的 BYOK 不再有 token 费用和限制。同时推出免费 Hobby 档、不加价的 Teams 档，零数据/最小化数据保留政策扩展到全部用户和工作区。要注意：让 Agent 独立并行运行的远程云虚拟机 orbs 仍需按量付费；在自己电脑上用 runners 跑 Agent 则免费。
**为什么值得关注**：AI 编程 Agent 的定价战继续往「只收算力、不收软件费」方向走，对成本敏感的个人开发者是实质利好。
🔗 https://ampcode.com/news/free-agent

**4. Qoder CLI 自 v1.1.50 起支持自定义模型接入**
所有个人用户（含免费档）均可使用，只需填 Base URL、Model ID、API key 即可接入。
**为什么值得关注**：国产 AI IDE 系产品开始把模型选择权交给用户，方便接自建/第三方模型，摆脱厂商锁定。
🔗 https://x.com/qoder_ai_ide/status/2098620121363399105

**5. OpenCode：deepseek-v4.1-flash 四倍用量活动再延一周**
原本为配合该模型上线 day 0 support 推出的 72 小时活动，现已延长一周。
**为什么值得关注**：延续 OpenCode Go 的拉新节奏，deepseek-v4.1-flash 想借高额度抢占编程 Agent 用户习惯。
🔗 https://x.com/opencode/status/2098759021171777938

**6. Altman 明确表态：2026 年不会上市**
接受《财富》采访时称，鉴于当下围绕安全的诸多情况，此时上市「不明智」，OpenAI 会「在准备好时」上市——即业务就绪且判断技术在社会层面的时机合适。他直接回应 2026 年「不会」上市，理由是还有很多事要做。此前报道称 OpenAI 已保密提交 IPO 申请。
**为什么值得关注**：保密递表与实际时间表之间出现明显落差，意味着 OpenAI 在安全监管叙事与资本节奏之间的权衡仍在摇摆。
🔗 https://fortune.com/2026/09/12/sam-altman-interview-ai-doomsday-safety-models-control-ipo-2027/

**7. 月之暗面法务部：网传创始人及员工信息系恶意造谣，已报案**
声明称相关内容纯属虚构，已第一时间向公安机关报案并将追究法律责任，呼吁不信谣不传谣。
**为什么值得关注**：国内大模型公司近期舆情压力上升，此类法务声明密集出现，值得留意是否有后续司法进展。
