## 1. 「有人花五位数买下中转站 6TB 数据」：企业在 AI 面前裸奔，今天吵得最凶

## 3. 「AI 这么强，跨端框架还有意义吗」：native 变便宜后，胶水层的价值被抽走

（程序员节点，13 楼讨论）楼主引用 Shopify 从 React Native 全量转原生：AI 加持下，重构成原生的时间和成本都降下来了，而性能提升是实打实的，于是问 RN / Electron / Taro 这类跨端方案还有没有存在价值。评论区基本共识是「跨端的原始理由（省人力）被 AI 削弱了」，但在「省 token」和「省 UI 统一成本」上出现分裂。

- **6 楼 @faceRollingKB**：「跨端方案自己的问题导致的成本已经超过了单独的开发成本，已经不划算了」——最直接否定派，逻辑是 AI 让「一次编写多端运行」的收益低于跨端本身带来的坑。
- **9 楼 @wizChen**：「目前感觉跨端方案只有热更这一个优势了……甚至可以根据一端的代码生成其他端的，体验又好」——给出判定标准：跨端只剩热更新，独立开发者做 native 反而更好。
- **12 楼 @aikilan**：「框架不再是技术关注的焦点，LLMS 完美符合我们的开发习惯之一『抽象』……所以它成了新的上位胶水层是必然的」——把讨论拔高一层：AI 本身正在取代框架做「胶水」。
- **4 楼 @SeanChense（❤1）**：「省 token，一个 token 当三份用你想下」——反方最简洁的成本论。

## 4. 同一条提示词，Claude Code 烧的 token 是 opencode 的 2~5 倍
