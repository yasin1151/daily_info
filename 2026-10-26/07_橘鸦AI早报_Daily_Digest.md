
**橘鸦AI早报 2026-10-25 摘要**（今日无 10-26 期，最新为 10-25，共 4 条主稿，已拆成 5 条）

**1. WorkBuddy 内测「收入变现」：技能可以卖钱了**
核心变化：开发者开通后可在开放平台发布付费「技能」和「专家」，自设一次性买断价或月订阅价；内测期平台服务费 1%；可查收入账单、跳微信提现；已发布的免费资产暂不支持转付费；付费资产加密并只在云端运行，用于防复制。
影响：这是国内 Agent 平台第一次把「技能」做成可交易商品——1% 抽成是明显的补贴期价格（对比 App Store 30%），意在快速把生态从「免费小工具堆量」拉到「有人能靠它赚钱」。但「云端运行防复制」也意味着技能必须跑在平台侧，开发者失去部署自由，长期看是平台锁定风险。
https://open.workbuddy.cn/docs/monetization

**2. Qoder 1024 活动加场：再开一轮，需 10 万次助力**
核心变化：原定三轮补给提前全部解锁发放，因此额外开第四轮「神秘补给包」，需社区再累计 10 万次助力；新开通或升级 Pro 及以上者，在领取期内仍可领见面礼+前三轮共 10,240 SOTA Credits；活动 10/30 23:59 结束，各轮补给须在发放后 3 天内且不晚于活动结束前领取，领取后仅 24 小时有效。
影响：典型补贴换订阅的打法，但 Credits 限定只能用于 Sonus 模型、且有效期 24 小时，说明成本压力不小、且目标是拉高自研模型调用率而非通用额度。想薅的用户注意：囤不了，得在用之前领。
https://qoder.com/community-boost

**3. Claude Code 两名核心成员同日宣布离职**
核心变化：Thariq 发文称参与 Claude Code 一年多、见证项目规模增长超出预期，接下来先休息；Anthony Morris 称自己「创建了 Claude Code 桌面版」，表示 Anthropic 的使命是职业生涯亮点，将很快公布下一步。
影响：Claude Code 是 Anthropic 目前增长最快的产品线之一，两名成员在同一时间窗口出走，通常是产品线重组或被竞品挖角的前兆；「很快公布下一步」更像要去做新项目/竞品。短期值得观察的是桌面版（Morris 主导）的迭代节奏会不会放缓。
https://x.com/trq212/status/2113844051938054167
https://x.com/amorriscode/status/2113972174524674247

**4. 英国公布数亿英镑 AI 投资计划：芯片、人才、就业研究**
核心变化：投资爱丁堡的 AI 芯片设计能力；在曼彻斯特设立 NCSC AI Cyber Security Centre of Excellence 培养安全人才；每年投入 1000 万英镑研究 AI 对就业和产业的影响；另向 AI Security Institute 追加 1.2 亿英镑并投资网络防御。
影响：这套组合的重点不是「追模型」，而是补芯片设计、安全人才和就业影响评估这三块英国真正的短板，同时明确写着要「减少对他国技术的依赖」。就业研究单列预算，也说明英国政府在为 AI 导致的岗位冲击提前准备政策弹药。
https://www.gov.uk/government/news/chancellor-unveils-britains-ambitious-plan-for-ai

**5. 全球首个专门的 AI 生物安全机构 + 两大模型厂商给额度**
核心变化：英国以 1 亿英镑支持设立 AI Biosecurity Lab（AIBL），用 AI 理解、预防、发现和应对生物威胁，财政部称其为全球首个专门的 AI 生物安全机构；OpenAI 承诺 1 亿英镑算力与模型额度，Anthropic 承诺最高 1 亿英镑模型额度、可信模型访问权限及专项技术支持，两家合计最高 2 亿英镑。
影响：这是「政府出钱、模型厂商给额度」的国家客户模式，对 OpenAI/Anthropic 来说拿到的是政府背书和高价值场景入口（生物安全、网络安全），比单纯卖 API 更有战略价值；对欧洲「AI 主权」叙事是实打实的加分。另一面，生物安全领域的模型访问会带来越来越严的可信访问审查，前沿模型的开放度大概率继续收紧。
https://gov.uk/government/news/introducing-the-ai-biosecurity-lab
