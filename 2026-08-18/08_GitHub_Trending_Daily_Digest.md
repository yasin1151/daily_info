**2. ai-memory — Agent 编码 CLI 的长期记忆方案**
- 简介：为 Claude Code / Codex 等 agent 编码 CLI 提供长期记忆，并支持在不同 agent 厂商之间交接上下文（handoff），用 Rust 实现。
- 为什么值得关注：直击"Agent 每次会话都失忆"的痛点——跨厂商记忆交接是 agent 工程里还没被解决好的问题，作者 akitaonrails 是 Rails 社区知名人物，项目 3 个月已 2k stars（今日 +207），值得跟踪。
- 🔗 https://github.com/akitaonrails/ai-memory

**3. llmfit — 一条命令找出你硬件能跑的 LLM**
- 简介：覆盖数百个模型和 provider，扫描本地硬件（GPU/内存），直接告诉你哪些 GGUF/MLX 模型能在你机器上流畅运行。
- 为什么值得关注：本地模型玩家刚需工具，省去逐个试跑的折腾；支持 unsloth/MLX/GGUF 生态，32.2k stars（今日 +239），社区认可度高。
- 🔗 https://github.com/AlexsJones/llmfit
