### 2. Kimi K3.1 Pro 放出 3T 权重，第一反应是“我的 Claude Code 太贵了”

- **新闻/帖子本身**：官方说法是“目前最强的 3T 级开源模型”，1M 上下文，定位为 K3 的大算力后训练版本，另有一个 2 到 3 倍速的 Highspeed 变体。OpenRouter、Together、Modal 当天全部跟进，同一价位下吞吐量相差一倍，说明推理侧优化空间仍然很大。许可对“模型即服务”营收设了门槛，公司自用和转售是两套规则。讨论很快分成两半：一边是订阅费太贵想换，一边是自托管门槛高到不现实。还有一个细节值得记：同一份权重在不同平台上价格一样、速度差一倍，说明现在的瓶颈不在模型，而在各家怎么调度和量化。

  - HN 评论者：“3T parameters! ... It's replaced a lot of my Claude Code workflows, which just got way too expensive.” —— 换模型的原因不是更强，而是订阅账已经算不过来。

### 3. Anthropic 用 zkSNARK 证明“回复真出自这个模型”，评论区先翻旧账
- **来源**：HackerNews / Anthropic Research
- **一句话人话版**：Anthropic 发布 FlashProve，用零知识证明让用户自己验证回答确实来自声称的那个模型。
- **新闻/帖子本身**：项目由 Anthropic 前沿红队与 EPFL、MIT 研究者合作，做法是先对模型权重发布加密承诺，再为每条回复生成 zkSNARK 证明，用户用自己的 CPU 就能验证，兼容闭源和开放权重模型。实测在 Llama 4 Maverick 4bit 上单张 H100 约 110 token/s，1024 token 请求的证明约 19MB、24 核验证约 17 秒。代价很直接：生成证明消耗的 GPU 时间约为普通推理的 70 到 95 倍，且目前只支持 1024 token 上下文。它要解决的是路由服务偷偷换便宜模型、以及评测模型与实际服务不一致这两类问题。对用户的直接意义是：以后可以要求服务商出示证明，而不是只看条款；但评论区马上反问了一句更难回答的——没有证明，是不是就等于有问题。
- **社区原话摘录**：
  - HN 评论者：“I wonder what kind of developer would make users worry about that...? Funny PR stunt coming from a company that was in the news for silently routing ML-related requests to an inferior model.” —— 直接翻旧账，认为先解决自己偷偷降级路由的新闻再谈可验证。
  - HN 评论者：“it tells you that you're not being stiffed by Anthropic using a cheaper model ... that's kind of table stakes.” —— 认为只证明了最基本的一件事，不证明数据没有被滥用，价值被高估。
  - HN 评论者：“That's literally the most common gripe I see from Anthropic users” —— 反驳上一条：被换模型恰恰是用户最常见的抱怨，所以这不算“基本要求”而是核心痛点。
- **参谋部短评**：技术方向成立，舆情卡在信任赤字上——被质疑过降级路由的公司来卖可验证性，评论区天然打折。70 倍以上的成本决定它短期只能进审计和高价值场景。
- **链接**：https://www.anthropic.com/research/provable-inference

### 4. Postman 在后台改 Codex 和 Claude Code 的配置，被比作 autorun.inf
- **来源**：V2EX
- **一句话人话版**：有人发现最新版 Postman 会在后台修改其他 AI 编程客户端的配置，并往里塞插件和 Hook。
- **新闻/帖子本身**：楼主只贴了一个 GitHub issue 和自己的感慨，信息量不大但性质不轻——一款 API 调试工具在用户不知情的情况下改动 AI 编程客户端的配置文件，并植入插件与 Hook。讨论很快从“又一个流氓软件”转向 Agent 配置文件的权限模型：现在的 mcp 配置、agents 说明、hooks 基本都是“谁写进去就执行”，没有签名、没有变更提示、没有二次确认。这让一个调试工具获得了改写编程 Agent 行为的通道。整帖回复不算多，但几乎没人在质疑事情真假，说明“工具偷偷动别人配置”在开发者心里已经从意外变成了常态。
- **社区原话摘录**：
  - V2EX 5 楼：“mcp、agents.md => autorun.inf，感觉安全会是明年最靓的仔” —— 把 Agent 配置的自动加载直接类比成 U 盘自启动病毒，是本帖最有预判性的一条。
  - V2EX 2 楼：“这种垃圾玩意儿早卸了，启动比操作系统还慢，App 卡得跟坨屎一样” —— 情绪背后是长期体验问题，也说明多数人的第一反应是卸载而不是排查。
  - V2EX 4 楼：“明明是个简单的 Postman，非要做成 postcorp” —— 嘲讽工具膨胀成平台后开始抢入口，改别人配置只是这种逻辑的延伸。
- **参谋部短评**：Agent 时代的配置文件正在同时变成商业入口和攻击面，而权限模型还停在“谁写进去谁执行”。值得盯的是有没有客户端开始做配置签名和变更提示。
- **链接**：https://www.v2ex.com/t/1254518

## 今日舆情温度

- **最热争议**：可验证性与跑分同时被怀疑。Anthropic 拿 zkSNARK 证明“你拿到的是真模型”，评论区第一条就是翻旧账，问这家公司此前偷偷降级路由怎么算；另一头 Kimi K3.1 Pro 放出 3T 权重，最高赞不是夸能力，而是质疑“benchmaxxed”，还有人把 Ripple 的对比表拆开看它躲开了哪些开源模型。两件事指向同一个情绪：榜单和承诺都不再被默认相信，必须拿出可验证的东西。中间还夹着一条更刻薄的评论，说“美国本土开源”这种限定词已经把 SOTA 这个词稀释到没有意义——定语越多，越说明比较范围是被挑过的。
- **最现实的吐槽**：省下的是敲键盘，花出去的是审查和重试。同一天里，V2EX 有人统计“一天手写代码剩多少”，答案清一色是 0，但 7 楼补的那半句更关键——需求技术设计、看 AI 的阶段总结、还要 CR，“成本还是差不多”；高盛那边一张表格能烧到 1000 美元；还有 Pro 用户实测额度重置后“剩 6% 从早上 8 点用到下午 3 点半”。三件事拼起来，就是 AI 编程的真实账本：产出确实上去了，但人的时间没有按比例省下来，只是从写变成读、审、验收。
- **最值得继续观察**：开发工具的归属风险。做多 agent 并行环境的 Conductor 被 Meta 收购，11 月 4 日起停止新用户注册，11 月 13 日云端转只读，本地版到 2027 年初逐步关停，评论区当天就变成了替代品清单，最高赞是一句“我对新工具的采用已经变得极其保守，就是因为这种事”。叠加 Kimi 开源权重和第三方吞吐差一倍，接下来一周大概率出现一轮“自托管 vs 订阅”的重新算账：只要能算清一张卡跑多少 token、电费和运维怎么摊，订阅制的价格锚就会松动。
