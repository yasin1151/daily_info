
# 橘鸦AI早报 2026-11-05 摘要

本期 25 条，挑出 10 条真正有信息量的。主线很清楚：模型侧在打「小模型 + 便宜 + 开放权重」，产品侧在打「能动手（操作电脑、生成动图、管 agent）」，资本侧一天两起收购，抢的是 agent 编排层。

---

## 1. OpenAI 发布 Images 2.6：图像模型开始生成动图

**核心变化**：ChatGPT、Codex、API 三端同步上线。一句话描述动作或上传一张照片，就能把静态角色/吉祥物变成循环 GIF，生成后可调播放速度、逐帧编辑；人物、宠物图片可存为参考图反复调用。API 侧新增 GPT-Image-2.6 Flare（低画质最快 6 秒一张）与 Sunburst（高画质、多次编辑细节更稳），官方称整体提速 50%，支持图片标注指定修改位置、complexity 三档调节、导出 SVG。全部订阅档位开放。

**影响**：图像竞争从「画得好看」转到「能动画、能精确改局部、能复用角色」。GIF 生成对营销和社交素材是直接可用的产能，不再是 demo。价格与 2.5 完全一致（图像输入 8 美元/百万 token、输出 30 美元），说明 OpenAI 这轮用能力而非降价防守。

**链接**：https://openai.com/index/introducing-images-2-6/

## 2. 腾讯混元 Hy4 正式版：加入视觉和电脑操作

**核心变化**：Hy 系列首次引入视觉能力和电脑操作，能结合命令行与图形界面处理专业软件任务。官方数据：内部评测幻觉率从预览版 15.76% 降到 5.45%；与腾讯金融科技组织 213 位从业者众测 579 个真实金融任务，综合 3.04 分开源第一；游戏开发评测提升 19.1%。已上线腾讯云和 OpenRouter，价格与预览版持平（输入 0.834 美元、输出 2.501 美元每百万 token），权重计划近期开源，Hy4 Flash 也在路上。

**影响**：国产开源模型把「能操作电脑」做成了标配能力，同时价格压在闭源一个数量级的下面。对企业内部办公自动化落地是现实选项。官方自己也承认前沿数学、长程开发跟顶尖闭源仍有明显差距，别指望它替代顶级模型做硬推理。

**链接**：https://hy.tencent.com/research/hy4

## 3. 月之暗面开放 Kimi K3.1 Pro 权重：2.8T 参数，附限制条款

**核心变化**：完整权重已上 HuggingFace，2.8T 总参数、100 万 token 上下文。许可允许免费使用、修改、再发布、再许可与销售，但加了两道闸：做 Model-as-a-Service 业务、且被许可方及关联方任意连续 12 个月营收超 2000 万美元的，须先另签协议；用于月活超 1 亿或月营收超 2000 万美元的产品，界面须显著标注「Kimi K3.1-Pro」。官方称中期训练和 RL 阶段均已移除网络攻击相关数据。

**影响**：这是目前开放权重里参数规模最大的一档，但许可设计明显是「开源给开发者、防云厂商白嫖」。想自建推理的团队成本结构会变，想包一层 API 转卖的会被条款挡住。这套写法大概率会被后面几家抄。

**链接**：https://huggingface.co/moonshotai/Kimi-K3.1-Pro

## 4. 字节开源 Axion 1.0：权重、训练代码、数据一起放

**核心变化**：开源 Agent 基础模型，35B / 122B 两个 MoE 版本（分别激活 3B / 10B），训练只有两段 SFT（128K 上下文）加一段 RL，总协议 Apache 2.0。除了权重，论文、训练代码、约 1.8 万条训练数据、评测脚本全部公开，面向科学推理、信息搜寻和工具增强的问题求解。

**影响**：Agent 模型的开放竞争已经从「放权重」卷到「放配方 + 放数据」，复现门槛被大幅拉低。对想做垂直 agent 的小团队，这是能直接改的底座，不用再从零对齐工具调用。

**链接**：https://axion1-0.github.io/ ｜ https://huggingface.co/Axion1-0/Axion-1.0-35B

## 5. Ripple-65B：65B 稠密模型在 agentic coding 上压过大模型

**核心变化**：Ricursive Intelligence 首个模型，65B 稠密、12 万亿 token 从零预训练、支持 100 万 token 上下文。公司称 TerminalBench 2.1 拿到 80.5%，超过参数量大得多的 Reflection Beam 501B、Meta Muse Spark Open 816B，刷新美国开放权重模型最好成绩。训练预算 3200 万美元，约为此前同类最强开放权重模型的十分之一。权重 Apache 2.0，已上 HuggingFace，也可通过 GMI Cloud、OpenRouter 调用。

**影响**：又一个「小模型 + 好数据」打败「堆参数」的案例，而且成本叙事更狠——十分之一预算换榜首。这类结果连续出现，会让「参数规模当护城河」的说法越来越站不住。技术报告还没发，具体怎么做到的待验证。

**链接**：https://ricursive.com/ripple ｜ https://huggingface.co/ricursiveAI/Ripple-65B-Preview

## 6. Cognition 推出 SWE-2 Flash：便宜 5 倍、快 3 倍

**核心变化**：基于 Thinking Machines 的 Inkling-Small，276B 总参数 / 12B 激活，成本是 SWE-2 的五分之一、速度快 3 倍，官方称在领先评测上优于所有美国开放权重模型，包括参数量大 3 倍的。训练配方上首次在强化学习之前加入 mid-training 阶段。已上线 Devin Desktop 和 Devin CLI，11 月 30 日前对 Pro、Max、Teams 免费。

**影响**：编程 agent 进入「够用且便宜」的竞争阶段，价格战从 API 打到订阅。值得注意的是权重不公开，Cognition 说要建一个面向行业伙伴和研究者的安全共享计划——前沿 coding 模型开始集体收紧开放度，和 Kimi、字节的方向正好相反。

**链接**：https://cognition.com/blog/swe-2-flash

## 7. 一天两起收购：OpenAI 买 Pierre，Meta 买 Conductor

**核心变化**：OpenAI 宣布收购 Pierre Computer Company，即开源工具 Trees、Diffs 和 Code Storage 的开发方，其中 Trees 和 Diffs 已经在给 Codex 的文件浏览、代码审查供能；目标是让 Codex 变成团队和 AI 从想法到发布的协作平台，让 Git 工作流适配 agent 协作。开源项目继续开源，Code Storage 逐步并入 Codex，交易待监管批准。同一天 Meta 确认收购 Conductor——让工程师同时管理多个编程 agent 的工具，即刻停止新用户注册，云服务 11 月 20 日关停删数据，订阅退款，本地客户端维持到 2027 年初。

**影响**：两家抢的不是模型，是 agent 的「协作层 / 编排层」——谁管住多 agent 的调度和代码审阅界面，谁就管住工作流。对 Conductor 用户来说这是个明确的迁移预警，云上数据 11 月 20 日就没了。

**链接**：https://openai.com/index/openai-to-acquire-pierre ｜ https://conductor.build/announcement

## 8. OpenAI 自主流程给 948 个 Linux 内核漏洞生成补丁，API 花了 121 万美元

**核心变化**：安全团队搭了一套自主漏洞研究流程，用即将发布的网络安全模型跑 Linux 内核：一次运行复现 1724 个漏洞，为其中 948 个本地权限提升漏洞（可让普通本地用户拿到 root）生成候选补丁，另为 291 个信息泄露漏洞产出 PoC。全程 API 成本 1,213,430 美元。Agent 发现并使用了至少 10 种被认为是新发现的利用技术。结果由人工研究员审核后向维护者报告。

**影响**：安全研究的经济学被改写——这个量级的人力覆盖以前不可能做到，而 121 万美元对大厂不算大钱。同一套能力攻击方也能用，所以补丁速度变成关键变量。这是本期最值得盯的一条，后续维护者的采纳率比数字本身更重要。

**链接**：https://openai.com/index/a-thousand-fewer-paths-to-root

## 9. Claude Code 调整游戏开发限制：提名字不再被拒

**核心变化**：Claude Code 2.1.317 修改了 Opus 5.5 的游戏开发限制。用户现在可以直接提某款现有游戏、让 Claude 参考其玩法机制做同类型原创游戏，不再被直接拒绝；明确要求复刻原作仍然拒绝，改为建议做体验类似的作品。此前系统提示词里加的两条规则导致「仅作玩法参考」也会被拒，引发开发者不满，Anthropic 工程师 Addy Osmani 亲自宣布了这次调整。

**影响**：版权边界从「提到名字就拦」改成「看意图判断」，方向对，但判定权交给模型仍然会误伤。这条的价值在于它是被开发者反弹推着改的，说明 coding agent 的系统提示词限制有多容易被用户体感成「不可用」。

**链接**：https://x.com/addyosmani/status/2117848568535106001

## 10. ChatGPT 被曝筹备五档家庭订阅，最高 500 美元/月

**核心变化**：有用户在 ChatGPT 网页端结账定价配置里发现 Family Basic 系列五档：Go 8 美元、Plus 20 美元、Pro Lite 100 美元、Pro 200 美元、Pro Max 500 美元，均为税前价。OpenAI 尚未公布或确认。

**影响**：订阅分层继续往下切，Pro Lite 填的是 20 到 200 美元之间的大空档，500 美元的 Pro Max 明显指向重度 agent / 高算力用户。家庭共享则是拉新的下一步。虽然是传闻，但定价配置出现在结账页，通常离上线不远。

**链接**：https://x.com/btibor91/status/2117875196594209270
