**热门评论**：
- **#3 clemente**："环境类的自己提前打包准备好所有可能用的工具，每次让 agent 自己找自己下很浪费 token。统一 harness + skill 对齐有点用" —— 立场：环境打平能省大量 token，统一 harness/skill 是可行路径。
- **#9 ntdll**："通常没有，这类工具我直接 yolo 模式在 docker 里运行，什么都别问我。就是干。哪怕搞坏了，最多就是重启容器的事情" —— 立场：隔离环境让"放权"零风险，浪费点 token 无所谓的激进派。
- **#4 ldy619354397（楼主）**："工具类调用可以明确告诉 AI 本机已安装，按文档路径直接调用，不用重复安装" —— 立场：规范里显式声明本机工具清单，避免 agent 重复装浪费。
