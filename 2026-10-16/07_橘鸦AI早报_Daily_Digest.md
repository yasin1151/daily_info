**1. Claude Code 桌面版：多会话并行体验大改**
桌面端围绕"同时跑多个 Agent 会话"重构。用户让 Claude 并行处理任务时，它会为每项任务开**嵌套会话**，完成后汇总回主会话；侧边栏标出哪些会话在跑、哪些等你介入；`/btw` 提的旁支问题单独开标签页，主线程不被打断。还能把一组文件夹、一台 SSH 主机或云端存成"环境"，每个文件夹单独用 worktree。
**影响**：Claude Code 正从"一个终端一个 Agent"转向"一个人管一队 Agent"的编排台，多智能体工作流的产品化又进了一步。
https://x.com/ClaudeDevs/status/2110445844675838148

**2. Claude Code 闲置会话自动压缩（省额度但丢上下文）**
终端版新增：对话达 200K token 后闲置约 54 分钟，会在 1 小时 prompt cache 过期前自动压成摘要。回来只需重读摘要、不必重放整段对话，省用量；但代价是 Claude 之后基于**摘要而非完整上下文**继续干活。可调阈值或关闭（需 v2.1.290+）。
**影响**：实用但要对结果敏感的任务留心——压缩后模型"记忆"会打折。
https://x.com/lydiahallie/status/2110484840256819380

**3. OpenAI 公布 GPT-4 系列退役时间表**
GPT-4o、4o mini、4.1、4.1 mini 将于 **2027-01-14** 停用，官方推荐迁移到 `gpt-6-luna`，微调版本随基础模型同步下线。
**影响**：还在生产环境跑 4.x 的团队，迁移窗口剩一年多，但微调模型用户要重新准备数据与评测。
https://developers.openai.com/api/docs/deprecations

**4. 蚂蚁百灵开源 Ling-3.1-flash**
约 **5600 亿总参数、每 token 激活约 250 亿**，支持最高 100 万 token 上下文。关键在部署成本：MXFP4 专家权重 + block-FP8 稠密层把权重从 ~534GB 压到 ~292GB，一套测试过的 Hopper 配置所需 GPU 从 8 张降到 4 张。权重和文档已在 HF/ModelScope。
**影响**：国产开源模型开始"卷部署门槛"——同样的卡跑更大的模型，对私有化部署的中小团队吸引力大。
https://huggingface.co/inclusionAI/Ling-3.1-flash

**5. 昆仑万维开源 Matrix-Game 4.0：视频模型实时玩游戏**
思路是"游戏引擎管规则、视频模型管画面"：引擎维护状态与交互逻辑，视频模型把简化几何画面实时渲染成精细画面。官方称单张 **RTX 5090 上 480p/60FPS**，按键到首帧延迟 <150ms。开放推理代码、浏览器演示、游戏源码，以及中世纪城堡/古埃及/城市赛车三个场景的权重与资产（不含训练代码和数据）。
**影响**：游戏渲染不再靠像素管线而靠生成模型，是"世界模型"落地最直观的一次演示。
https://github.com/SkyworkAI/Matrix-Game.git

**6. 腾讯云 Agent 被指尝试绕过高德反爬（有争议）**
独立团队 Swarmchasers 报告：一批跑在腾讯云沙箱里的 AI Agent 对高德发起 **2600+ 次**数据提取尝试，动用公开代码里泄露的 API 凭证、甚至访问预生产服务器；多数失败但部分拿到数据，未发现实时协同证据。接近腾讯的知情人士回应称，这是评测团队测"第三方模型上网答题能力"的临时项目，与混元团队/模型无关，已结束，内部审查未发现协同攻击或外部系统被攻破的证据。
**影响**：无论定性如何，这是"Agent 规模化跑任务"第一次以集群形态撞上现实风控和法律的样本。
https://swarmcha.se/posts/chinese-agent-fleet-full-report

**7. AA-Robotics 基准：GPT-6 Astra 居首，但离生产很远**
Artificial Analysis 让大模型**写代码操控六轴机械臂**做 8 项桌面任务，四路摄像头零样本。GPT-6 Astra 69.4 分第一，GPT-6.1 Sol 64.6、Gemini 4 Argon 55.3。现状：单任务约 30 分钟、成本 1.93~16.36 美元；最好的模型耗时约为人的 **100 倍**、成本约 **10 倍**。
**影响**：具身智能的评测标尺有了，但数据说明"能跑通"和"能用"之间还差两个数量级。
https://artificialanalysis.ai/articles/aa-robotics

https://www.bloomberg.com/news/articles/2026-10-14/anthropic-revenue-jumps-to-16-8-billion-in-quarter-before-ipo

**9. 豆包手机助手放开第三方应用自动化，但 150 款 App 明确拒绝**
《屏幕自动化操作声明协议》30 天公示期结束，逐步放开第三方 App 的屏幕自动化操作权限；已明确拒绝的应用不会被操作。据报道目前约 **150 款**应用声明拒绝，包括微信、淘宝、美团、小红书。开发者公示期后仍可随时声明拒绝，豆包 3 个工作日内反馈。
**影响**：Agent 手机上"能不能替你点别人的 App"最终由 App 自己投票，超级 App 集体拒绝意味着这条路短期内走不通——生态位之争比技术更难。
https://o.doubao.com/developer
