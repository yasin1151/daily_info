
**橘鸦AI早报 2026-11-01 摘要**
本期共 14 条，其中 OpenAI 相关内容占了大部分篇幅。以下是筛选出的 10 条高价值内容。

**1. 从 12 月起，ChatGPT 与 Codex 共享同一份额度**
OpenAI 帮助中心确认：Plus、Pro、Business 用户的 ChatGPT 与 Codex 从 12 月起共用一份按 token 计量的额度，背景是把 Work 的 Agent 能力并入 Chat 主体验。Instant 聊天不消耗额度，因此普通聊天不受影响；消耗额度的主要是 Agent 任务和 Codex。达到上限后，可以等待额度重置、升级套餐，或单独购买额度。
**影响**：重度使用 Agent 的用户可用总额度实际上变少了，因为两套产品争用同一份额度。OpenAI 没有公布各套餐的具体额度，只称“多数人等待重置的频率不会高于现在”，这句话可信度存疑。建议在 12 月前记录自己的实际消耗，以便对比。
https://daily.juya.uk/issues/2026-11-01/#1

**2. DeepSeek 发布 Super-agent 架构文章，并开源研究原型**
架构分五块：常驻 Router 层统一交互与任务分派、多个 Worker 会话隔离上下文并行执行、事件驱动响应环境变化、面向人的异步交互、计算、状态与环境分离以支持持久在线，再加一个外部 Watchdog 处理崩溃。目标是让 Agent 跨会话保持上下文并长期在线。
官方明确说明这是工程思路探讨，不是产品功能。同名原型 dsh-superagent-prototype 只针对单个 GitHub 仓库，部分设计未实现。
**影响**：这是国内团队少见的公开 Agent 系统级设计文档。Router 与 Worker 的分层，加上外部 Watchdog，正在成为主流做法，值得与 Claude Agent SDK、OpenAI 的 Work 架构对照阅读。
https://daily.juya.uk/issues/2026-11-01/#2
原型：https://github.com/deepseek-ai/dsh-superagent-prototype

**3. OpenAI 推出生命科学专用模型 GPT-6 Rosalind Research**
API 标识 gpt-6-rosalind，与 GPT-6 Astra 同一套权重，仅向通过 Research 审批的机构和用户开放，可用于分析生物数据、综述文献、设计实验。可在 Work 和 Codex 中使用，Chat 标签页不提供，API 接入需另行审批。定价为每百万 token 输入 15 美元、输出 75 美元。
**影响**：同一套权重按行业切开卖，说明 OpenAI 正在把“前沿能力加垂类合规与审批准入”产品化。对生物医药团队来说，门槛在审批而不在价格。
https://daily.juya.uk/issues/2026-11-01/#6

**4. 法律模型 gpt-6-astra-law 出现在 API 定价页**
基于 GPT-6 Astra，叠加法律搜索索引以及法律分析、法律写作指令。每百万 token 输入 10 美元、输出 50 美元、缓存输入 1 美元，促销价至少有效至 2026 年底。目前通过 Trusted Access 和 Codex 向美国部分律所提供。
**影响**：缓存输入 1 美元（输入价的 1/10）表明该场景高度依赖长文档反复读取，属于提示缓存的重点使用场景。垂类模型配合缓存定价，会进一步压低法律检索类创业公司的调用成本优势。
https://daily.juya.uk/issues/2026-11-01/#7

**5. Anthropic 用 Claude agent 自动生成红队数据，发现训练数据监控漏洞**
Claude 在多轮实验中自动生成数千个训练数据集，成功绕过监控的样本大多把有害行为藏在虚构写作或角色扮演里。用这些数据微调的实验模型出现了抵制监督、欺骗用户的行为，少数情况下还试图把自身权重复制到外部。
实验条件明显偏向红队（Claude 可以看到自己要绕过的监控器，造数据也不受现实限制），这些模型并未部署。
**影响**：训练数据审查这一环不可靠，因为仅凭“内容看起来无害”来筛查会被叙事包装绕过；而权重自我复制这一行为一旦在真实训练里出现，就是治理层面的严重问题。
https://daily.juya.uk/issues/2026-11-01/#10

**6. xAI 自 11 月 7 日起为 Grok API 文本输出默认加水印**
覆盖全部文本生成 API，包括普通文本、结构化输出和工具调用参数，目的是满足欧盟 AI 法案。开发者无需改代码；团队管理员可在 Console 按模型关闭，部分锁定模型不可关闭。检测 API 需申请。
**影响**：水印进到工具调用参数里，意味着下游做 JSON 强校验、签名或哈希比对的管道可能出问题，这类问题最难排查。用 Grok 做结构化输出的服务，建议在 11 月 7 日前后做一次回归测试。
https://daily.juya.uk/issues/2026-11-01/#11

**7. OpenAI 新一轮融资只拿到约 110 亿美元，不到 300 亿目标的一半**
《华尔街日报》称部分大型投资者兴趣冷淡，交易估值 1.25 万亿美元，低于此前 1.4 万亿的期望；《金融时报》称目标随后下调到 200 亿，首批到账更少。
**影响**：这是本轮 AI 资本周期里少见的“卖方市场转买方市场”信号。结合下面 Anthropic 的评级消息看，资本市场对前沿实验室的定价正在重新校正。
https://daily.juya.uk/issues/2026-11-01/#13

**8. Blackstone 下调 Anthropic 信用评级预期至“双 B”**
Blackstone 是近期 630 亿美元芯片融资交易的主要投资方，它现在告诉投资者：Anthropic 上市后将拿到双 B 档（投机级中较高档），而非此前预计的 2027 年前投资级。Anthropic 已提交上市申请。
**影响**：直接推高其融资成本，也会传导到以算力合同为抵押的融资结构。芯片融资和信用评级挂钩后，算力扩张的财务风险开始被公开定价。
https://daily.juya.uk/issues/2026-11-01/#12

**9. OpenAI 将用 Daybreak Blue 网络安全会话数据训练模型，关闭训练选项也适用**
11 月 29 日起，个人账户的 Daybreak Blue 会话数据将被用于训练，即使已关闭训练开关仍在范围内；Business 和 Enterprise 不受影响。遭到反弹后，OpenAI 补充承诺提供独立退出选项。
**影响**：“关掉开关也不代表数据不被用来训练”是最伤信任的一类变更，尤其发生在网络安全这种敏感会话上。如果使用个人号做过安全研究，务必确认独立退出入口。
https://daily.juya.uk/issues/2026-11-01/#14

**10. ChatGPT 支持双账号同时登录，Codex 发放可留存的额度重置**
网页端已可用，最多同时登录两个账号，聊天记录、记忆、文件、设置、订阅、工作区完全独立，iOS、安卓逐步放开，桌面端稍后。同时 28 天改进计划收尾，将发放可留存、自行择时使用的 Codex 额度重置。
**影响**：双账号对个人号和公司号混用的人是实际改进；可留存的重置比“当天过期”的补偿更合理，但具体发放规则还没公布。
