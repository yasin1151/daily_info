## 7. 可以只备案域名，不买国内服务器吗
`1241953 · 技术节点 · 16 回复`

**为什么值得关注**：备案、CDN、源站三者关系是国内建站必踩的坑，这条帖把规则和几个低成本绕过思路都讲清楚了，属于可以直接抄作业的工程经验。

- **17 楼 @mytsing520**：CDN 节点的 IP 地址由 CDN 服务商在电信行业备案系统里做过 CDN 用途报备，因此在实际应用中不可被当做「源站 IP」用途使用；接入商会通过自己的备案审计系统查看你备案的域名是否经过了「源站」。
- **16 楼 @goojia**：我闲鱼买的阿里备案码备案，备案之后 www 域使用 hexo + GitHub Pages + 阿里云 CDN 搭了个静态博客。博客没啥流量，所以 CDN 直接按量计费，约等于免费。
- **7 楼 @383394544**（误区，已被上面纠正）：可以吧，腾讯 edge 的 ip 不就是国内的 ip 了吗？
- 补充 **6 楼 @MagicalCarl**：买腾讯云函数的包年套餐包，几十块钱、能永久用，之后建一个云函数按量使用，解析到这个云函数就行。
