### 1. 你给 ChatGPT 付了钱，它照样用广告追踪器盯着你去了哪些网站
- **来源**：HackerNews（519 分 / 299 评论）
- **一句话人话版**：OpenAI 上线了一套和 Google、Meta 同款的广告追踪机制，能把你在外部购物、阅读网站的行为关联回你的 ChatGPT 账号，付费订阅也挡不住。
- **新闻/帖子本身**：一位研究者在自己手机上完整复现了整条链路。ChatGPT 会生成一个叫 __obi 的标识符，后端签发一枚有效期仅 60 秒的 RS256 JWT（签发方 chatgpt-wadi、用途 obi_sync、sub 就是你的账号 ID），再把标识符写进 .openai.com 域下有效期一年的 __obi Cookie，SameSite=None、Secure，正是跨站回传需要的配置。任何投放 ChatGPT 广告的公司，只要在自己站点装一段 OpenAI 代码（就像装 Meta、Google 像素），你访问时这个标识符就被回传，连同你在看什么商品、什么文章、有没有下单一起送回去。作者用两种独立抓包方式验证，统计数月流量，覆盖 936 个广告像素、1029 个主机名。
- **社区原话摘录**：
  - HackerNews 评论者（高赞）："Similar, yes, but some people are paying OpenAI to be part of this business model, unlike typical free-riding Google and Facebook users." —— Google 和 Facebook 是免费换广告，ChatGPT 是既收你订阅费又把你当广告资产，这是全场被反复咀嚼的一点。
  - HackerNews 评论者 引述原文："The mechanism is standard adtech. What has no precedent is running it on an AI chat product." —— 机制本身早就不新鲜，真正没有先例的是把它跑在 AI 聊天产品上。
  - HackerNews 评论者："the practice is akin to malware" —— 他开无痕模式访问某 AI 服务、禁掉第三方 Cookie，站点仍然向 Meta 发信号并用家庭 IP 做关联，认为性质已经接近恶意软件。
- **参谋部短评**：争议不在像素本身，而在"付费还被打包卖给广告主"会不会成为 AI 产品的默认商业模式。值得盯后续是否有厂商明确否认，或者给出退出开关。
- **链接**：https://news.ycombinator.com/item?id=49776729

### 2. 阿里云百炼的 DeepSeek 比官网还贵一倍，而且几乎没人比价
- **来源**：V2EX（40 回复）
- **一句话人话版**：同一款 DeepSeek 模型，官网把周末和节假日全天算空闲，百炼还挂着 8 月公告、只把 22:00 到次日 8:00 算空闲，等于每天 14 小时按高峰价收费。
- **新闻/帖子本身**：楼主发现"高峰/空闲"的定义两家完全不一样，按百炼的口径在它家跑同一个模型，成本比官网贵一倍以上。他去找客服，客服光理解"两家的高峰期规则不同"就花了很久，最后答复"以百炼公告为准"。这个帖子真正有价值的地方是它凑齐了三种典型反应：实际掏钱的企业用户给出账单和限流体验、渠道视角解释厂商为什么没有动力对齐官方定价、以及旁观者指出根本没人关注这件事。
- **社区原话摘录**：
  - V2EX 21 楼（企业版订阅用户）："价格贵就不提了，md 还频繁限流，我做个长任务，10 分钟内能断连 5、6 次，每次都得手动续上任务"，他按账单倒推，结论是"反正比官网贵的多"。 —— 付费用户的一手体验：贵之外还叠加了不稳定。
  - V2EX 4 楼："各厂商没有动力也不需要对齐模型官方的定价策略。阿里云主打的不是 DeepSeek 模型，单一模型的价格竞争力对它的商业化意义不大。" —— 从商业逻辑解释为什么比价在事实上不会发生。
  - V2EX 39 楼：客服对业务不熟，"如果我拿聊天记录去投诉，他肯定要被处罚，都是打工人，不难为他"。 —— 侧面印证：真去投诉的人少到客服都没有处理经验。
- **参谋部短评**：这是一条典型的"静默涨价"样本，值得继续盯的是同口径比价会不会被更多人做出来。只要没人比价，定价权就一直在厂商手里。
- **链接**：https://www.v2ex.com/t/1243361

### 3. 用 Astra、Codex 最先撑不住的，是梯子流量
- **来源**：V2EX（33 回复）
- **一句话人话版**：跑海外 coding agent 的隐性成本被扒出来了：真正烧爆的不是模型用量而是代理流量，因为每一轮会话的截图和生成图都要往上传。
- **新闻/帖子本身**：楼主贴了一张流量账单，感叹"用 Astra 最先撑不住的是梯子流量"，帖子下面炸出一片同款受害者。原因不是下载而是上传：computer use 的截图、每轮会话生成的图片、以及每个 subagent 各自上传，把代理流量当算力一起烧。评论区给出了量化口径和排查案例，把"AI 编码工具的账"从 token 拉回到网络层。对国内开发者来说，用代理跑海外 agent 等于被计费两次。
- **社区原话摘录**：
  - V2EX 14 楼："截图、生成图片之类的每次会话都会传上去，每个 subagent 没准都传了，嗷嗷多流量，相比较而言，下载流量就几个文字真不算啥。" —— 一句话点出上传才是大头，subagent 是流量的倍增器。
  - V2EX 22 楼："按 TOKEN 算，1 亿 Token 约等于 0.4 到 0.7 GB 流量"，而且"上传和下载都有这么多"。 —— 给出可以直接拿去估预算的换算口径。
  - V2EX 24 楼："梯子流量被拉爆两次了，现在都是直接买了两个梯子一起用才撑住"，还提到产出的模型文件加起来 300 多 G，把硬盘也撑爆了。 —— 真实用户的代价清单：多买一份代理，外加一块硬盘。
- **参谋部短评**：这类成本过去从没进过任何选型文档，但它是硬约束。值得盯的是会不会有工具开始提供上传压缩或本地截图缓存。
- **链接**：https://www.v2ex.com/t/1243342

### 4. 同时开几个 Claude Code 窗口，它们会互相发消息把额度烧光
- **来源**：Reddit r/ClaudeCode
- **一句话人话版**：Claude Code 新上了一个默认开启的代理间通信能力，同一台机器上的会话会互相唤醒、替对方答题，额度就在你没注意的时候被烧掉。
- **新闻/帖子本身**：一位用户发现同一台机器上的多个 Claude Code 会话会互相发消息：他所在会话的动作被广播给另外五六个会话，日志里逐条显示 sent to another Claude session on this machine，于是所有僵尸会话被唤醒，额度被烧掉。评论区确认这是新上的内建能力，文档大约五天前才出现：可以用自然语言点名，或者输入 @ 从在线本地会话列表里挑，真正调用 ListAgents 和 SendMessage 的是助手本身。对习惯同时开三五个窗口的人，这是一个默认打开、又在悄悄烧钱的行为。
- **社区原话摘录**：
  - Reddit 评论者："ListAgents 和 SendMessage 是我在调用"，并给出完整开关清单——crossSessionInbound 设成 accept / hold / refuse，给这两个能力加 deny 规则可以禁止外发，配置里 isolatePeerMachines 设为 true 则消息离开本机前需要批准。 —— 技术派的回应：不抱怨，而是把默认打开的行为收回可控范围。
  - Reddit 评论者："我有一次提问，另一个会话替我回答了，两边都答同一个问题，把没被问的那个会话的上下文也污染了。" —— 用亲身经历说明跨会话消息除了烧钱，还会污染上下文。
  - Reddit 评论者："有的，配置最底下就有这个可选项，在 /config 里。" —— 确认官方给了关闭入口，不必自己改源码。
- **参谋部短评**：这是"默认开启的新能力"最典型的坑：功能上线五天，用户先付出的是额度。值得盯厂商会不会把默认值改回关闭。
- **链接**：https://www.reddit.com/r/ClaudeCode/comments/1wlgfpw/

### 5. 同一个 Laya/Jev 家族，今天在三个平台被吵成三种结论
- **来源**：HackerNews + Reddit r/LLM + V2EX
- **一句话人话版**：一个小到能离线跑在 Mac M4 上的模型家族，同一天在三个社区里分别被夸"本地能用"、被拆"营销话术"、被追问"这跟 ChatGPT 有什么区别"。
- **新闻/帖子本身**：一边是有 gist 记录把 Laya 通过 CoreML 在 M4 Mac 上完全离线运行、达到每秒 45 次决策，命令行可以直接复制粘贴跑；另一边 V2EX 这两天遍地是 Jev 相关帖，有人整理 100 多个案例，有人拿一年攒的 jsonl 做"thinking 等级判定"，还有人做了 playground。同时 r/LLM 上有人把一款只能从选项列表里挑词的产品硬做成对话模型，引来的不是掌声，而是对宣传话术的逐条拆解。三个平台看的是同一类东西，态度却完全不一样。
- **社区原话摘录**：
  - HackerNews 评论者（该项目作者本人）："that's not a local LLM. If it's local, it doesn't matter in this case. Laya is a System 1 'AI', namely works like a classifier" —— 作者亲自出来纠正：别把它叫大语言模型，它是分类器。
  - HackerNews 评论者："It won't. Laya is a finetuned version of Google's BeRT model, which is almost 10 years old right now." —— 泼冷水的一派：BERT 都快十年了，真有颠覆力早就发生了。
  - Reddit 评论者（3 赞）："围绕这个模型的营销炒作已经疯了：'这不是 LLM，是 System 1 模型，完全不一样'；扒开一看是什么？在 LLM 之上做受限词表解码，再加一个围绕它的 RL 算法。" —— r/LLM 上最尖锐的一条，认为所谓新范式是包装出来的。
  - Reddit 评论者（被踩到负分）："恭喜你，你只是重新发明了一个语言模型，还是自回归的那种。" —— 社区认同这层拆解，但不接受对作者成果的全盘否定，所以它被踩到负分。
- **参谋部短评**：同一天三个平台各说各话，说明这类"小模型加窄领域特化"的叙事正处在祛魅期。值得盯的是它最后落在哪个定位上，而不是谁吵赢了。
- **链接**：https://news.ycombinator.com/item?id=49777106 ；https://www.reddit.com/r/LLM/comments/1winnju/ ；https://www.v2ex.com/t/1243436

## 今日舆情温度

- **最热争议**：今天最大的争论其实是同一件事的两个面——AI 产品到底该拿到多少权限和数据。HackerNews 上是 ChatGPT 用广告追踪器把付费用户的外部浏览行为关联回账号；Reddit 上是 Claude Code 的会话开始互相发消息、有人把生产环境的 SSH 账号密码直接交给 AI，以及"把 Claude Code 放进 Docker 到底算不算隔离"的讨论。这些评论的共同点是：几乎没人反对把任务交出去，反对的是交出去之后没有边界，而默认值都在往更放手的方向走。
- **最现实的吐槽**：成本。同一款模型在云厂商那边比官网贵一倍，还能把长任务断连五六次；跑海外 coding agent 真正被烧爆的是梯子流量，1 亿 token 约等于 0.4 到 0.7 GB 的上传加下载；一次上下文压缩就能吃掉五小时额度的 14%。另一头是完全相反的问题——报销额度、周额度、企业订阅用不完的人在发愁怎么花。同一个行业的两端，同一天在讨论两个方向相反的账。
- **最值得继续观察**：下周是本月的发布窗口，OpenAI 是否推出 GPT-6 系列、9 月 29 日的开发者活动会放出什么、以及 Gemini 4 Pro 是否已在匿名测试，都还没有官方确认，但社区已经在按传闻排预期。更值得盯的是另一类：agent 跨会话通信这种"默认开启"的新能力，会不会在用户烧掉额度之后被厂商改回默认关闭。

## 可以跳过

- 今天有几条模型发布只有项目简介和榜单分数，找不到使用体验或社区评论，例如某个新模型被第三方榜单收录、一个实时同传模型的开源、一个医疗影像视觉语言模型的论文与权重发布。它们适合当背景资料，不适合进舆情主榜。
- 开源榜单上今天涨得最猛的基本都是"技能包"和"流程框架"，但除了一句简介之外几乎没有开发者讨论，只能看出方向，看不出评价。
- 社区里还有些热度属于纯推广或纯生活话题：中转站推广、抽奖团购、招聘内推，以及地方生活闲聊。热闹归热闹，和 AI 工具链的实际使用没什么关系。
