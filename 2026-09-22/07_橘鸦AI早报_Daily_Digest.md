**1. Qwen 开源 Qwen-Image-2.1：文生图与图像编辑合并成一个模型**
阿里 Qwen 放出 Qwen-Image-2.1 权重，把文生图和图像编辑统一进同一个模型，视觉生成部分仅 7B 参数、32 层 Single-Stream DiT。三个关键能力：原生支持 RGBA 透明图生成与编辑（也能从普通照片里抠主体成透明图层）、最多吃 10 张参考图、圈选/涂抹/独立掩码等局部编辑；同时强化了人像身份一致性和商品文字、纹理、形态保真。推理侧用混合粒度注意力和 KV Cache 复用降低多图重复计算。
**影响**：7B 可本地跑 + 发布当天 Diffusers/ComfyUI/vLLM-Omni/SGLang/LightX2V 全部跟上，意味着"统一生成+编辑"这条路线第一次以开源小模型形态落地，做电商图、透明素材、信息图的团队可以直接替换现有拼装管线。
原文：https://qwen.ai/blog?id=qwen-image-2.1

**2. 阶跃星辰 Step 5 Preview 全量开放：600B MoE、27B 激活、百万上下文**
阶跃发布旗舰基座 Step 5 Preview，稀疏 MoE，总参 600B / 激活 27B，支持 100 万 Token 上下文与视觉输入，明确瞄准 AI 编程、软件工程、金融等 Agentic 长任务（多轮工具调用、持续执行）。官方称 Artificial Analysis Intelligence Index 得 44 分、全球开源模型前三，单任务成本为 Claude Opus 5 的八分之一。现已上线官方 API 和 Step Plan，**权重 10 月 15 日开放**。
**影响**：卖点不是分数而是"成本 1/8 + 百万上下文 + 工具调用"，这是冲着 Coding Agent 的长会话成本去的；权重开放日期已定，届时可自部署评估。
原文：https://www.stepfun.com/step-5-preview

**3. Google 开源 Agentic 编排器 AX：K8s 上有状态 Agent 任务**
谷歌在 GitHub 开源 AX，用声明式方式在 Kubernetes 集群里编排有状态自主 Agent 工作负载。核心是 Task / Workspace / Gateway / Model 四类配置，定义运行环境、资源、网络和模型，底层靠 Agent Substrate 做沙箱隔离，并支持任务的暂停、恢复和调试。官方目标是在单集群跑数十亿任务，Apache 2.0 许可。
**影响**：这是把 Agent 从"脚本调用"推向"云原生工作负载"的基础设施级尝试——有状态 + 沙箱 + 可暂停是生产环境真正卡住的点。但项目还在早期，官方明说稳定版前可能出现破坏性变更，不建议现在绑死生产。
原文：https://github.com/google/ax

**4. 腾讯开源 WeVisDoc：2B/4B 端到端文档解析，直接出带公式表格的 Markdown**
WeVisDoc 提供 2B 和 4B 两档权重（基于 Qwen3-VL-2B/4B-Instruct 微调），把页面图像一步转成结构化 Markdown，在同一输出序列里同时保留文本、LaTeX 公式、HTML 表格和阅读顺序。官方称 4B 版在 OmniDocBench v1.6 及 PureDocBench 的 Clean / Digital Degraded / Real Degraded 四项设置中均领先所比较的端到端解析模型。
**影响**：端到端替代"检测+识别+版面重建"的拼接流程，2B 就能本地跑，退化扫描件场景也有实测数据支撑——RAG 预处理、财报/论文入库这类苦活可以直接换。
原文：https://tencent.github.io/WeVisDoc/

**5. WebCraftBench：让 Agent 真的去点网页，用代码覆盖率查漏**
腾讯混元联合清华、北大提出 WebCraftBench，评估 AI 生成网页应用的美观度、易用性和需求符合度。思路上的改变是：不再只看代码或首页截图，而是让 Agent 实际操作网页，用代码覆盖率辅助判断哪些功能没被触达，再基于运行证据打分。数据集含 369 条真实用户需求、5088 条验收标准，覆盖 17 个模型生成的 6273 个应用；论文称 197 组有效应用对中 168 组与人工复核偏好一致，一致率 85.3%。
**影响**：给"AI 写前端"提供了一个可落地的评测范式——截图好看但功能是空壳的情况终于能被量出来，做前端 Agent 的团队值得直接拿来当验收基准。
原文：https://arxiv.org/abs/2609.15387

**6. TypeSafe AI 向所有用户开放 Jev，新用户送 5 美元额度**
TypeSafe AI 取消候补名单，所有用户可通过在线控制台直接调用 Jev 模型；每位用户初始获 5 美元额度，官方称约合 1.2 亿 token。
**影响**：纯试用门槛变化，量对得上就值得开个号跑一下；除此之外没有产品能力更新的信息。
原文：https://console.typesafe.ai

**7. 硅基流动完成 B+ 轮二期和 C 轮融资，年内累计近 29 亿元**
投资方包括中国互联网投资基金、国新基金、中国移动链长基金等，部分老股东追加。资金投向推理引擎、异构算力调度、模型与芯片适配，目标是强化 Token 供应平台并拓展全球市场。
**影响**：国产推理/Token 平台进入拼融资和算力调度的阶段，对开发者最直接的意义是后续价格竞争和区域可用性（尤其海外节点）可能继续改善。
原文：https://mp.weixin.qq.com/s/Y0X4FqYFYQDsTLGyLl0dzQ

**8. 智谱 MaaS 将上线"数据内容不留存"功能**
用户可在 MaaS 控制台申请开通，生效后输入输出不做静态存储，仅用于当次调用。例外有三类：Batch API、File API 等需要持久化的功能不在覆盖范围；因法律法规要求，或为核查违规/滥用，平台可能留存 30 天及以上。具体生效时间与适用范围以平台确认为准。
**影响**：面向企业和开发者的合规卖点，但"核查滥用可留存 30 天+"这条实质上把"不留存"限定在常规推理路径上——对合规敏感的客户，签约前要把例外条款和 Batch/File 路径分开谈。
原文：https://mp.weixin.qq.com/s/e7kLxQKhkOrLdsmgyF5U0Q
